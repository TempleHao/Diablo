# 归墟 2D · 界面规则

每次改界面都要先过这份清单，不能只照着单条需求改。自动检查见 `tests/2d-ui-layout.test.mjs`，它覆盖 8 种屏幕尺寸，在 CI 里运行。

## 0. 头号原则：任何界面都不能超出手机屏幕

这是不可让步的原则，每次改版都要先过这一条。

- 所有看得见的东西（标志、按钮、状态条、文字、职业按钮）都必须完整地在屏幕里，四边都不能被切掉，也不能故意做成「出屏」效果。
- 刘海、圆角、底部横条区域要让开：四边位置一律加上 `var(--st/--sr/--sb/--sl)`。
- 只有两种例外：放在可滚动容器里、能滑出来的内容；整屏铺满的背景图层。
- 自动检查 `tests/2d-ui-layout.test.mjs` 会在手机尺寸下模拟刘海（竖屏上 47、下 34；横屏左右 47、下 21），把登录、选角、游戏三个界面里所有可见元素逐个检查是否出屏，CI 不通过就不能发布。

## 1. 优先级：战斗画面最大

1. **战斗画面中央**（以角色为中心、半径约 40% 屏高）不能被常驻界面挡住。常驻界面只能放在四个角和上下边。
2. **常驻界面的高度**：电脑上下合计不超过屏高的 25%，手机不超过 35%。
3. **会弹出的面板**（行囊、状态、暂停）打开时暂停或遮住战斗。这时其他浮动按钮（传送阵、有更好装备提示）要让开，不能盖在面板按钮上。

## 2. 不重叠，不出屏

- 同一屏上的两块界面不能相交。标志、信息栏、角色列表、账号提示、技能面板、血条各有固定区域。
- 所有按钮都在可视区内，不出现横向滚动条。刘海、圆角和底部横条区域要让开（`env(safe-area-inset-*)`）。
- 主操作（进入游戏、创建并进入、穿戴）在首屏内就能看到。手机竖屏时，主按钮排在说明文字前面。

## 3. 层级与密度

- 一屏只有一个主按钮（暗红漆面），其余按钮用铸铁样式，危险操作（删除）放在角落，并且需要确认。
- 大标志只出现在「进入游戏前」的界面（选角、开场弹窗）。游戏中的顶栏只用小徽记和金属字标题，避免细节缩小后糊成一块。
- 文字：标题用衬线字，正文不小于 12px（手机 11px），不用纯白，主要文字用米黄 #ecdcb8。

## 4. 统一的组件

| 组件 | 样式 |
|---|---|
| 面板 | 铁框 + 金线内框 + 石质噪点 + 四角铆钉 |
| 普通按钮 | 铸铁牌，悬停发光，按下凹陷 |
| 主按钮 | 暗红漆面金边 |
| 选择框 / 输入框 | 刻槽 |
| 小卡片 / 格子 | 凹槽 |

新界面直接用这些类名，不另写网页风格的样式。

## 5. 触屏

- 可点区域不小于 40×40px，技能格不小于 42px。
- 手势区（摇杆）与按钮区不相邻，误触时不能触发危险操作。

## 6. 角色选择的版面

| 屏幕 | 版面 |
|---|---|
| 电脑（宽 ≥ 900 且高 ≥ 560） | 右侧固定信息栏，宽 clamp(320px, 27vw, 430px)，账号提示在信息栏顶部；左侧是舞台列。标志在舞台列顶部居中，高 clamp(80px, 18vh, 190px)，舞台从标志下方开始。列表模式下，角色列表在最左侧，舞台列向右让出位置。 |
| 手机竖屏 | 从上到下依次是标志、舞台（单人轮播）、主按钮、职业按钮和名字、介绍。 |
| 手机横屏 | 左列放标志和舞台，右列放可滚动的信息。列表模式没有空间，不显示标志。 |

## 7. 登录页的版面

标志是登录页的主角。标志图的四边都做了渐隐，任何尺寸下都不能露出一条硬边，也不能被表单压住。

| 屏幕 | 版面 |
|---|---|
| 手机竖屏 | 上方是星空和城堡剪影，标志用去掉两侧外缘的窄版，完整放在屏幕里；下方是贴底的表单。键盘弹出时整页可以滚动，标志不会被顶出屏幕。 |
| 手机横屏 | 左边是标志（窄版），右边是表单。 |
| 电脑 | 大标志（约 66% 屏宽）和窄表单作为一组垂直居中。 |

自动检查：标志完整在屏内、高度不小于屏高的 15%、不和表单相交；「登录」和「游客进入」两个按钮不用滚动就能看到。

## 8. 改界面的流程

1. 先按上面 1–6 条检查方案，冲突时以「战斗画面最大」和「不重叠」为准，并在回复里说明取舍。
2. 用 1920×1080、1440×900、1280×720、1024×768、390×844、360×640、844×390、667×375 八种尺寸截图看一遍。
3. 运行 `node tests/2d-ui-layout.test.mjs` 和浏览器冒烟测试，都通过后再发布。
