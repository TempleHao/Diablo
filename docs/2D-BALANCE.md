## 1. 技能伤害预算

所有伤害以角色的攻击力/法术强度 **P** 为单位（技能等级 0，不含装备加成）。

| 类型 | 规则 |
|---|---|
| 普通攻击 | 每秒 2.2P，不耗资源；随武器攻速变化 |
| 主力技能（冷却 ≤ 1.2 秒） | 每秒 3.0P（单次 = 3.0 × 冷却，冷却至少按 0.35 秒算） |
| 爆发技能（冷却 > 1.2 秒） | 单次 3.6 + 1.0 ×（冷却 − 1.2），与主力技能叠加，所以折算每秒较低 |
| 范围系数 | 单体 1.0 · 穿透/小范围 0.85 · 中范围 0.7 · 大范围 0.6（打得越多，单人伤害越低） |
| 控制为主的技能 | 眩晕 ≥ 1.2 秒、冻结 ≥ 1.5 秒、强击退、恐惧、骨墙：再 × 0.5 |
| 召唤 | 满编时合计每秒 1.8P（单只大型随从 1.3P） |
| 陷阱/图腾 | 满编时合计每秒 2.0P |
| 伤害光环 | 对范围内每个敌人每秒 0.8P |

每个技能先按设计数值估算，再乘以系数 bal 对齐预算（bal 限制在 0.3–4）。技能等级每级 +12% 伤害。

## 3. 装备

- 武器强度 =（6 + 2.5 × 基底强度）× 品质倍率（白 1 / 蓝 1.2 / 黄 1.4 / 橙 1.65 / 金 1.85）× 双手 1.4 ÷ √攻速。慢武器单次更痛、快武器出手更多，普攻每秒伤害基本一致。传奇 / 暗金 / 套装的基底强度不低于物品等级的 85%。
- 词缀成长：生命、法力、护甲、强度、回复、吸血等固定数值随物品等级线性成长（每级 +5.5%）；暴击、增伤、抗性、攻速、移速等百分比成长平缓（60 级 +70%），避免堆爆。
- 品质对词缀数值的加成：普通/魔法 ×1.00，史诗 ×1.08，传奇 ×1.22，暗金 ×1.32；词条数量：魔法 1–2，史诗 3–4，传奇 3–4 + 传奇特效，暗金 4–5 + 更强特效，套装 3–4 + 套装加成；60 级以上史诗 / 传奇 / 暗金各 +1 条。

## 4. 怪物与难度曲线（v0.7.3）

怪物等级由难度和区域决定（见 progression.js）。
- 生命 = 基础 × 种类倍率 × 2.45 ×（1 + 0.16(L−1)）×（1 + 0.0125(L−1)）× 难度（普通 1 / 噩梦 1.6 / 地狱 2.5）
- 伤害 = 基础 × 种类倍率 × 1.5 ×（1 + 0.085(L−1)）×（1 + 0.012(L−1)）× 难度（1 / 1.35 / 1.75）
- 第二个括号让怪物成长跟上「角色等级 + 装备」的成长；1–10 级有新手缓冲（从 6 成逐步到满额）。噩梦 / 地狱怪物出手快 8% / 16%，移动快 5% / 10%，玩家全抗 −20 / −40。
- 护甲减伤 = 护甲 ÷（护甲 + 70 + 12 × 怪物等级），上限 75%：同样的护甲，打高等级怪减伤更少（原来是固定 ÷(护甲+200)，高等级时总是 60% 封顶，地狱打起来不痛）。

按「每个部位一件蓝 + 一件黄、略低于当前等级」的典型装备估算（单体持续输出，不含范围技能打多个目标）：
