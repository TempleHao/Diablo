# 归墟 · 装备命名系统（v1.6，已实施）

> 目标：名字有出处、有质感，不堆砌形容词。东方取中国古文与古代兵器，西方取欧洲古兵器、法器与西方奇幻传统。
> 词库：scripts/2d-naming/lexicon.py（每个词附出处）；生成：scripts/2d-naming/build_names.py → dist/2d/naming-data.js；运行时：dist/2d/naming.js。

## 1. 为什么现在的名字「土」

| 现在的名字 | 问题 |
|---|---|
| 寂灭之坠、灵柩行迹、葬钟指印、裂魂之胄 | 暗黑意象叠在一起，用词偏网文，「寂灭、噬魂、葬钟」用得太多 |
| 坚韧兽牙带·暖炉、驱暗狂战兽甲·炎盾 | 前缀加基底再加后缀，6–9 个字，读不顺 |
| 星穹大法师·冠冕、天穹女武神·战衣 | 「星穹 / 天穹」这类大词没有出处 |

## 2. 世界观依据：两种遗物都漂进了归墟

「归墟」出自《列子·汤问》：渤海之东有大壑，「八纮九野之水，天汉之流，莫不注之」。

所以游戏里的装备都是从四方漂进归墟的遗物，**每件都有出身**：
- 东土的器物，按中国古制命名；
- 西境的器物，按西方古兵器和奇幻传统命名。

**一个名字只用一套词库**，绝不把「青铜鸩毒骑士阔剑」这种东西混在一起。

## 3. 两套词库

### 东土（中国古文、古兵器）

- **兵器基底**：环首刀、横刀、陌刀、斩马刀、长剑、短剑、匕、戈、矛、戟、钺、殳、锏、铁鞭、骨朵、角弓、长弓、蹶张弩、神臂弓、旁牌、藤牌。
- **防具首饰基底**：兜鍪、明光铠、鱼鳞甲、山文甲、札甲、裲裆、臂鞲、吊腿、蹀躞带、玉佩、韘（扳指）、璜。
- **工艺 / 品相**（普通装备，由差到好）：生铁 → 熟铁 → 百炼 → 错金 → 鎏金。
- **元素前缀**（魔法装备，按数值高低换字）：
  - 火：烛 → 燧 → 燎
  - 冰：凉 → 霜 → 冱
  - 雷：电 → 雷 → 霆
  - 毒：苦 → 蛰 → 鸩
  - 光：明 → 昭 → 煌
  - 暗：晦 → 幽 → 冥
  - 暴击：利 → 锐 → 铦
- **后缀（铭文款识）**，按数值高低升一级：
  - 生命：貉 → 熊 → 罴 → 夔
  - 法力：蜃 → 蛟 → 虬 → 应龙
  - 护甲：「坚壁」「金汤」
  - 寻宝：「探骊」（典出「探骊得珠」）

### 西境（欧洲古兵器、法器、奇幻传统）

- **兵器基底**：阔剑、手半剑、弯月刀、长戟、长柄斧、钉头锤、晨星锤、连枷、战锤、骑枪、复合弓、长弓、十字弩、小圆盾、鸢盾、塔盾。
- **法器基底**：法杖、魔杖、权杖、法球、魔典、骨杖、圣物匣。
- **防具首饰基底**：大头盔、锁子头巾、轻盔、锁子甲衫、胸甲、罩袍、铁护手、胫甲、护身符、印戒。
- **品相**（普通装备，由差到好）：生锈 → 粗铸 → 淬火 → 大马士革 → 符文。
- **元素前缀**：
  - 火：余烬 → 灼热 → 熔铸
  - 冰：寒露 → 凛冬 → 永冻
  - 雷：静电 → 雷鸣 → 天罚
- **后缀**：照《暗黑破坏神 2》用动物阶梯，按数值高低升一级：
  - 生命：豺 → 狼 → 虎 → 猛犸
  - 法力：蜥 → 蛇 → 飞龙 → 巨龙
  - 吸血：水蛭 → 蝗 → 七鳃鳗

## 4. 每个品质怎么命名

| 品质 | 结构 | 东土示例 | 西境示例 |
|---|---|---|---|
| 普通 | 品相 + 基底 | 百炼横刀、熟铁兜鍪 | 淬火阔剑、生锈锁子头巾 |
| 魔法 | 前缀 + 基底 · 后缀 | 霜横刀·蛟、鸩匕·罴 | 凛冬阔剑·猛犸、灼热魔杖·飞龙 |
| 史诗（随机） | 二字意象 + 一字器称 | 白虹锋、朔风戟、孤鸿弓、寒星佩 | 战霜、鸦宴、鲸路靴（北欧比喻：战霜指剑，鸦宴指战场，鲸路指大海） |
| 传奇（手写） | 名器专名 | 承影、含光、宵练（三剑都出自《列子》） | 格拉姆、杜兰达尔、冈格尼尔 |
| 暗金（手写，带传记） | 名器加一段典故 | 鱼肠：专诸把剑藏在鱼腹里刺杀吴王僚 | 杜兰达尔：罗兰在龙塞斯瓦耶斯山口的最后一战 |
| 套装 | 套装名 · 部位 | 干将莫邪 · 雄剑 / 雌剑 | 圆桌 · 胸甲 |

## 5. 质感规则（也写进自动检查）

1. **字数**：除了暗金，全名不超过 6 个汉字。
2. **出处**：每个词都要能说出出处或实物。词库里每个词都附一句注释（出处或是什么东西），没有出处的词不收。
3. **禁用词**：寂灭、噬魂、灭世、至尊、无上、混沌、神魔、魔神、深渊之、永恒之、之王之。
4. **暗黑意象**：一个名字里最多用一个（骨、血、亡、冥、葬选一个）。
5. **一眼看出是什么**：普通和魔法装备的名字里一定保留基底名（横刀、阔剑）。史诗和传奇装备在详情里另外显示基底。
