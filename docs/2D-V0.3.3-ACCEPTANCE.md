# 2D v0.3.3 Demo：角色清晰度、技能构筑与自动分解

**性质**：用户反馈驱动的试玩版增量，非写实暗黑 A 方向最终美术交付。**状态判定须以 PR 的真实 Chromium CI 结果为准**。

## 用户提出的问题与落实

| 反馈 | 实现 | 尚有限制 |
| --- | --- | --- |
| 旧法师角色头部模糊且显老 | 原创清晰 Canvas 矢量披风法师，增加独立兜帽、胸甲、肩甲和法杖轮廓，换装品质改变披风、头部与武器色泽 | 是临时高可读角色，尚未达到用户希望的写实 2.5D 高质量多方向骨骼/逐帧动画 |
| 只有少量主动技能 | 7 → 11：连锁闪电、冰暴领域、奥术护盾、烈焰地径；等级解锁、真实伤害/持续效果/护盾，保留所有旧技能与点数 | 手机与 PC 保持 7 个可操作快捷栏，技能图鉴可以把新技能替换进快捷栏；不是把 11 个按钮塞满屏幕 |
| 手动逐件分解太麻烦 | 默认关闭，用户可选择自动回收普通 / 普通与魔法 / 普通至稀有；掉落拾取时可自动入库材料；新增背包一键按规则批量分解 | 已装备、收藏、传奇、套装始终被自动过滤，传奇/套装不会被系统擅自自动销毁 |
| 分解没有素材后续用途 | 原有精华继续保留；新增灰烬粉尘、奥术结晶和传奇余烬。装备详情按成本淬炼，成功会提高第一条随机词缀，且每件最多一次 | 这是第一阶段经济闭环：没有谎称已实现装备合成、复杂宝石镶嵌等未完成系统 |

## 安全与存档

- 保留浏览器旧键 `ember-chronicles-2d-v1` 及版本号 `2`；自动扩容新增材料、自动分解阈值、技能栏配置和两种物品标识（收藏、已淬炼）。
- 未导入时默认自动分解关闭。稀有品质自动回收需用户**主动选中**；传奇与套装被排除。
- 默认装备技能栏为原 7 项，已有点数、等级和装备均保留。每次只能装备 7 个技能，修改快捷栏不会扣除技能等级。
- 装备淬炼必须检查金币+材料是否充足，先验证生成的新装备合规，再消耗材料与金币；二次淬炼拒绝。
- 继续使用原图集绘制怪物与现有九区域地砖，因此本轮技术进步不能视为最终视觉方向合格。

## QA 门禁

- 旧存档迁移、安全性和材料上限；四种新增法术必须可以施放并产生不同机制。
- 背包自动回收不能误拆已装备、收藏、传奇或套装。掉落被自动分解后进材料钱包，不占背包空间。
- 装备淬炼一次后面板属性确实改变，刷新浏览器后仍保持已淬炼状态和投入的材料数量。
- PC 1365×768 / 手机 390×844 的真实 Chromium 截图，11 个技能图鉴、7 个可用快捷栏、分解选择器、材料钱包和淬炼面板可读，没有 Javascript 异常。
- 角色更换前后真实游戏画面，不允许将项目外的高精度参考插画标为“游戏实机”。
