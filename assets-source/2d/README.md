# 黑铁遗珍 / Black Iron Relics — 装备系统 V1.0

原创暗黑奇幻风格角色扮演游戏装备设计案。对应之前生成的五张装备图鉴。

## 资源目录

- `equipment_catalog_500.json`：500个可读的装备定义（含属性、等级、特效、词缀、掉落与图标路径）。
- `equipment_catalog_500.csv`：适合导入后台的平面表。
- `icons/N/`、`icons/M/`、`icons/E/`、`icons/L/`、`icons/U/`：五个层级对应的500个切割图标，分别100个。
- XLSX设定案见压缩包中的 `黑铁遗珍_500件装备系统设定与名录.xlsx`。

## 5个品质层级

| 编码 | 品质 | 主色 | 词条 | 战斗身份 |
| --- | --- | --- | --- | --- |
| N | 普通 | 灰白 | 0 | 基础装备与锻造材料 |
| M | 魔法 | 蓝 | 随机1–2 | 常规属性强化 |
| E | 史诗 | 紫 | 随机3–4 | 流派定型 |
| L | 传奇 | 橙 | 随机3–5、1独特特效 | 技能形态变更 |
| U | 暗金遗珍 | 暗金 | 固定4词条、2段机制、属性代价 | 终局遗物与鲜明的取舍 |

## 数量结构

- 100件形态原型 × 5品质 = **500件独立ID、独立装备名称**。
- 每种品质图谱源图片为 **10列×12行=120格**，本版从中挑选100个图标格。
- 每件装备记录 `atlas_row` 与 `atlas_col`（从1开始）及裁切图标文件路径。
- 整体兼容七职业偏好：亚马逊、刺客、野蛮人、德鲁伊、死灵法师、圣骑士、法师。
- 装备槽：主手、双手、普通副手、独立箭袋、头、肩、胸、手、腰、脚、项链、双戒指。

## 系统规则

1. 先进行装备掉落判定，再根据怪物等级查品质概率，然后在合法掉落池中筛选原型、道具等级与专属来源。
2. 词条围绕霜、雷、血、圣光、风、岩、火、毒、暗影9种主题分布。
3. 双手近战武器及双手法杖占用双手；**双手弓/弩允许装备独立箭袋槽**。
4. 可以装备2枚戒指；不能同时装备两件同名暗金。
5. 暗金不保证在所有流派里都优于传奇，特殊效果与代价共同确定价值。
6. 制造、洗练、镶孔与分解玩法见Excel“玩法与开发规则”。

## 使用提醒

本包是**游戏设计原型和原有图鉴的切图**，并非严格真实的6×6/12×12像素绘制。图标尺寸约111×92裁切像素，原生显示时需要基于UI规格重新调整或重绘。数值是初版平衡参数，需要结合玩家血量、战斗公式、怪物强度以及实际掉落进行测试。所有名称、词缀和效果均为原创设定，不属于《暗黑破坏神2》的官方装备内容。
