# 双轨美术交付纲领（v0.3.5 生效，必须长期遵守）

## 不可改变的双轨方向

1. **当前试玩 Demo**：允许用用户 2026-10-14 提供的六色小像素法师参考（蓝、红、白、紫、绿、冰蓝）及前面的精致像素法师立绘，优化临时可玩体验。应有可辨认人物/装备、较小且适配手机的比例、待机/跑动/施法/受击状态和脚步动效，不能靠一张完全静止不动的插画平移。Demo 允许像素风；这种美术只能视为过渡资源。
2. **最终 A 方向正式版**：仍然以用户 **先前确认的写实暗黑 2.5D、斜俯视、石质地牢、写实人体比例、精致怪物/装备、火光冷调、PC+手机 UI** 的五张参考图为唯一最终视觉验收标准。像素卡通试用风格 **绝不可覆盖或替代最终方向**。

## 当前试玩修复范围

- Demo 的新角色切换到参考像素法师：优先落实蓝色奥术法师，贴图真正出现在可运行游戏画布中；其余五色为未来换装皮肤预留，不能把未实现的皮肤记为已完成。
- 待机有呼吸轻摆；行走有两层（上身与下摆/脚部）分别变化、左右身体倾斜、身体重心升降、足底粒子；施法有抬手倾斜、光球/法环；受击有短暂闪烁。此轮属于 **单原始角色图的程序化过渡动画**，非传统逐帧手绘 8 向行走动画，报告必须如实区分。
- 触摸端缩放沿用 v0.3.4 小比例（手机 .54、PC .65），不扩大人物遮挡地图。
- 旧角色的矢量文件保留为载入失败的 fallback，可回退。保留所有装备、地图、Boss 奖励、技能、分解、锻造和浏览器存档数据格式；3D 项目完全隔离。

## 门禁与测试记录

- 上线前必须通过 Node JS 语法/规则测试、Chromium 电脑 1365×768 / 手机竖屏 390×844 / 手机横屏 844×390 浏览器游戏交互和新精灵资源加载校验。
- **仅接受运行真实网页得到的截图**：固定同一个可运行种子记录待机和按键移动期间的两张图，优先留手机端与桌面端；素材设定图不得充当截图。
- 如果测试不通过、角色明显裁剪、动作出戏、存档丢失，保持 PR Draft 不合并。
- 角色参考素材由用户在对话中提供，用于当前试玩版改造；素材权属/可公开再分发范围未单独提供书面许可证明，因此后续可复制的高质量正式版资产须另选**原创或明确授权**的素材，不将此视为整个项目素材均可自由再分发。

## 冲突处理

任何自动开发任务读取本纲领时，都必须优先保留正式 A 方向，不可因 Demo 本轮改成像素风，就把正式美术门禁 G05/G06 标成 pass。试用版体验可以快速改进并发布，但最终版只有用户确认实际游戏实机质量才可完成。
