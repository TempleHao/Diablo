## 一、项目概要

黑铁遗珍是一套完整可检索的暗黑幻想装备目录。采用“**一百种外观/功能原型 × 五个品质版本**”的数量结构。不同品质版本拥有独立ID、独立名称、属性与各自的图标格位；**这500件是500个定义，而非500个随机词缀结果**。

| 指标 | 数量/范围 |
| --- | --- |
| 装备总数 | 500件（500个独立ID；500个不同名称） |
| 基本形态 | 100种基础原型 |
| 品质数量 | 5阶；每阶100件 |
| 专属特效记录 | 200件（传奇100件 + 暗金100件；部分机制模板可复用） |
| 适配职业 | 亚马逊、刺客、野蛮人、德鲁伊、死灵法师、圣骑士、法师 |
| 装备需求等级 | 1—100 |
| 主题元素 | 霜、雷、血、光、风、岩、火、毒、暗 |
| 可装备部位 | 主手、双手、箭袋、副手、头部、胸部、肩部、手部、脚部、腰部、戒指、项链 |

### 设计目标

1. 普通装备有基础构筑与制作价值，而非纯废品。
2. 蓝色品质依靠随机词缀的优秀组合保有价值。
3. 紫色品质用于稳定成型战斗流派。
4. 传奇以独特触发能力推动技能玩法改变。
5. 暗金通过独有规则和负面代价构成终局选择，不承诺永远数值最强。

## 六、锻造、培养与约束

- **套装规则：**套装不是第六个品质：通过“同系徽记”在任意品质装备上组成2/4/6件协同，后续可增加绿色装备外观。
- **装备冲突：**双手近战/双手法杖占用主手与普通副手。弓和弩虽为双手，但允许同时激活独立箭袋槽。
- **戒指数量：**每人有两枚戒指槽；暗金同名唯一装备最多佩戴1件，避免机制无限叠加。
- **角色绑定：**偏好职业不表示全部硬锁；如职业基础武器与技能需要，开放兼容扩展。
- **怪物掉落：**先判断是否触发装备掉落，后按等级决定品质，再在可用装备池按部位和副本主题抽样。
- **掉落锁定：**怪物等级低于装备需求等级不能产出对应道具。暗金还要满足专属地图、BOSS或祭坛机制。
- **Boss保底：**每次地狱首领挑战提升“古王印记”积累；60枚可定向兑换一件指定类别暗金，非即时直接保底。
- **词缀生成：**蓝色随机1—2条、紫色3—4条、传奇3—5条加具名特效、暗金固定4条与专属机制。
- **不重复词条：**同件装备禁止同名词条出现2次；互斥的元素主要词缀最多1条。
- **镶嵌：**普通装备最多1孔，魔法最多2孔，史诗/传奇最多3孔，暗金最多4孔。实际孔位以物品数据为准。
- **洗练限制：**蓝色可以完整重铸；紫色可锁定1条；传奇可锁定2条；暗金只能重掷数值区间，不改核心效果。
- **品质提升：**普通装备可附魔升级为魔法；史诗以上不可通过直接消耗金币无限升阶。
- **装备传承：**消耗相应材料把低等级传奇机制转移为一枚继承符印；转移后原装备被消耗且受职业与等级限制。
- **拆解与制作：**普通→铁屑，魔法→奥术粉尘，史诗→灵质晶片，传奇→炽焰烙印，暗金→古王残响。
- **分数不等于强度：**面板评分不含技能回响、控制强度、团队价值和移动效率；终局强度必须通过流派战斗实测。
- **属性定义：**当前攻击、护甲、生命、法力等为原型平衡草案；施法速度、攻击间隔、抗性上限和伤害公式待引擎阶段定稿。
- **6px说明：**这批图片是模型生成的大图，经分格获得可展示的图标；不是严格6×6像素手工绘制。切图供原型UI参考。
- **许可说明：**名称、机制、数值是原创设计，用于暗黑幻想风格项目；不等同于暗黑破坏神2官方装备数据库。
- **推荐开发顺序：**第一阶段导入500件数据库→第二阶段调词缀池/战斗公式→第三阶段按真实16/24/32像素绘制精灵→第四阶段测试掉落曲线。

### 套装关系

套装并非第六个品质，后续可借“同系徽记”构建2/4/6件协同。对图标、套装名、增益数值和掉落列表应另开版本设计，不在本500件清单中虚构已实装套装。

### 图标技术约束

- 图标以 `icons/{N|M|E|L|U}/EQ-{稀有度}-{001..100}.png` 组织，500条JSON记录均有对应的相对路径。
- 概念图鉴每品质源图为10列 × 12行，共120格，本版本从每张图谱选取100格，一共裁切500张PNG。
- 裁切图标约111×92像素；**不是固定6×6px或12×12px的原生精灵**。它们只能视为美术原型，不宜作为严格低像素UI的最终交付。
- 若游戏角色精灵为64px高度，建议额外制定统一的装备原生精灵网格（例如16×16或32×32），再用最近邻缩放显示。此建议属于后续美术规范，不表示当前图标已经达到该网格。
- 使用时应重新处理黑底或透明通道、统一图标安全留白，以及材质/品质标识与装备图像的分层显示。

## 十、开发落地与校验

### 最小功能流程

1. 读取 `equipment_catalog_500.json`，用 `id` 建立装备定义索引。
2. 根据装备部位、职业偏好、双手和箭袋规则实现角色装备槽。
3. 战斗时读取攻防、生命、法力、主属性，并为传奇/暗金绑定专属触发效果。
4. 掉落时先执行“是否掉装备”，再按本表抽品质，最后按等级、来源与原型筛选ID。
5. 装备面板展示名称、品质颜色、基础数值、词缀、孔数、专属机制与负面代价。
6. 以游戏内实测数据调整掉落、技能触发概率、词缀数值和同系词缀叠加规则。

### 校验结果

- 500个装备记录；500个不同ID；500个不同名称。
