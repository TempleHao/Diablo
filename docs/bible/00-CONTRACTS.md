# 共同约定与版本边界

策划文档版本：1.0（2026-10-11）；游戏当前实际版本：0.2.0。以下全是计划、规则提案或验证标准，不代表 Demo 已实现，也不承诺已确定的开发周期与内容量。

## 统一世界词汇

暂定游戏名《归墟》，研发代号 VORAGH；现有 Demo 可继续显示《余烬法师》。世界是赫烬大陆。灾难称“断昼”，城市用“余烬炉”维持庇护。余烬是一种保存生命、记忆与魔力痕迹的能量，过度提取消耗记忆并可能被空潮侵蚀。对立力量“空潮”吞噬边界与身份。玩家为“持灯者”，以法师身份从灰烬营地出发。世界、角色、怪物、美术、技能和独特装备原创。

五幕：第一幕灰烬边境；第二幕盐雾海岸；第三幕镜霜高地；第四幕星坠王都；第五幕无昼深渊。开局主要伙伴：修灯匠诺娅、档案员塞恩、守门人瓦尔。最终对立角色：司炉长伊瑟，他相信必须控制全部余烬炉才能挽救大陆。重要概念统一使用以上名称，不自创另一套主线。

## 系统共同约定

1. 首个完整发布版本只做法师，支持火焰、冰霜、奥术三条路线与混合构筑。其他职业留接口，不列入首发交付。
2. 完整角色等级上限暂定60，具体升级曲线待测。首次剧情通关不是构筑成长终点；无需反复强制重跑五幕才能解锁终局。剧情支持随时降低难度、推荐构筑与免费早期重置。
3. 当前 Demo 的6槽计划可作为中间里程碑。完整版本装备位为武器、副手、头部、衣袍、手套、腰带、靴子、护符、戒指一、戒指二（10位）；双手法杖占武器并禁用副手，单手魔杖配法器。必须同时比较两槽价值。
4. 完整触屏战斗栏目标为主攻键 + 两个可选主动技能 + 固定位移 + 药水，共5键，另有移动摇杆。主攻有三元素的免费基础攻击；主动技能耗法力。持续效果/符文/天赋提供深度，不能靠继续增大高频按键数量。当前 Demo 四键布局保持作为过渡状态。
5. 技能符文改变行为，每技能先允许一个主要变体及后续一个辅助位；关键天赋和独特装备存在明确代价。路线成型不依赖极稀有独特物品。标签要支持命中/持续/触发/范围/投射物/元素的明确兼容。
6. 默认单人、永久角色成长。第一完整版本可本机存档和导出；云存档是独立阶段。联机、交易、赛季、硬核、排行榜纳入完整策划，但默认不是 GitHub Pages 单机版上线前置条件，不能假定客户端可信。
7. 核心资源：金币、精华、秘纹碎片。支线材料可作为任务物、配方部件、宝石与符文物品存在，不无理由增加平行货币。无体力门槛，无装备付费数值设计；商业模式待用户决定。
8. 默认死亡保留角色等级与已取得装备。契约失败损失该局未结算的风险奖励或可消耗入口物，不删除常规角色；硬核为可选未来模式。所有损失进场前明示。
9. 终局主要循环名“秘境契约”：选地区、等级档、挑战词条、奖励偏好；可重复获取入口，不迫使付费/等体力。地图图鉴/秘境网络、专项Boss与深渊远征可扩展。没有设定保证几百小时内容。
10. 装备基础品质：普通、魔法、稀有、独特、套装；带孔为并行属性，不单独代替品质。魔法1–2随机词条，稀有3–6（最高3前缀3后缀），独特手工效果与浮动数值。高级掉落、制造与特殊品质扩展须明确优先级。
11. 关卡采用设计模板的房间图与有约束的随机；验证可达、刷怪点、相机、避让空间。风险与奖励连接，禁止把敌人只涨血当作终局全体内容。
12. 普通关卡目标时长6–12分钟、Boss专项3–8分钟、远征可更长且设休息/保存点。这些都是试玩目标，不能写成实测数据。
13. 显示词条必须真实生效；明确同组加法与少量独立乘法、抗性/控制/触发边界；暴击、伤害与控制的精确数值只是初始校准提案。
14. 资料研究以暗黑II、暗黑III/IV和流放之路1的稳定设计为主，可补充流放之路2官方设计说明。区分官方事实、历史开发说明、我们的推论与原创提案。不要复制受保护素材或名称作为游戏内容。
15. 所有章节应覆盖玩家体验、完整规则、边界/失败、具体例子、数据字段、测试指标、分阶段交付。文字详细但不能堆砌同义重复。对其他章节机制只引用，不擅自改规则。

## 制作阶段

D0 当前 Demo：0.2.0，模型/场景/技能/法杖/本机存档。
D1 垂直切片：一幕局部、分工怪物、模板房间、两条完整构筑、六槽过渡装备、真实词条与基础掉落。
D2 系统 Alpha：三路线、十装备位、打造/宝石符文、任务/怪物图鉴、契约雏形。
D3 首个完整单人版本：五幕叙事内容、成体系敌群与Boss、完整构筑/掉落目标、稳定终局、真实手机质量。
D4 在线服务扩展：云存档/身份/合作/交易/赛季等，逐项评估成本与独立验证。

本约定是策划1.0各章共同基线；具体规则的维护归属见08章节，首页和阅读版从源章节生成。首发数量是内容预算方向，不是已制作库存或交付日期。
