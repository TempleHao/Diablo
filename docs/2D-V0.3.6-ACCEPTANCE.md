# 2D Demo v0.3.6 — 法师选择、密集战斗、魔法特效与地牢美术

## 两套美术方向绝不混淆

此次只修改 **当前像素风测试版**，沿用 [双轨美术纲领](2d-final/DUAL-ART-DIRECTION.md)。用户已经确认的最终 A 方向仍是高品质写实暗黑、斜俯视 2.5D、复杂多房间立体地牢、美术统一的怪物与人物、丰富装备图鉴。不许因为 Demo 的像素法师、多色换肤、程序绘制阴影等工作而将正式版的视觉门禁宣告通过。

## 已开发（以自动化测试和实际截图为准）

1. **五色法师**：同一位小法师有星辉蓝 / 赤焰红 / 圣辉白 / 虚空紫 / 自然绿五个外观配置。用户在开局或背包装备页选取，选择随本地存档保存，老存档回退蓝色。**是对现有原画逐像素程序换色**，尚不是用户参考图中五幅独立绘制的服装和头饰精灵，更不是完整 8 向走路动作表。
2. **敌人密度 x3**：所有九个区域由每次约 12 名怪物提升至总计 36 名，三波各 12。第 2、3 波分别加入至少两只强化精英，精英有额外生命和更高掉宝率，位置按不同方位散开，不再挤在原 4 个坐标。36 只怪完成才触发 Boss；保留 Boss 专属装备、自由拾取和地图传送阵。防止全场并发过多怪物（最多 24 名同时）。
3. **法术特效**：火弹由纯椭圆光点改成发光弹核与火尾，冰弹改为晶体飞矢；新增分层火焰、冰雪、奥术爆击粒子、扩展法阵、震荡环和残光表现，并依据实际施法和命中事件触发。单效果最多 44 颗粒子，同时最多 44 组，粒子生命周期结束自动清理。
4. **环境氛围**：真实碰撞石墙周围增加投影和石质描边、破裂地砖、残损纹理、火把光池与祭坛边缘。这只是地图氛围纹理提升。参考图中的连通房间、深渊、吊桥、不同高度与真实 2.5D 石造建筑尚未重构成功，继续单独开发。
5. **装备图标试修**：由极简 48 px 扁平矢量图改为 80 px 高分辨率图标，增加暗石雕花背景、锻造边框、体积投影、材质高光和词缀火冰色。保留头盔/法杖/剑/盾/戒指的明确装备外形；与用户期待的高品质写实装备素材仍有差距。如用户提供统一且可用于仓库的精致图集，可替换成真正贴图。

## 提交 / 上线门禁

- Node 单元测试检验怪物 36 只、波次 12/24、Boss 36、每波精英、五色存档和 VFX 数量/寿命。
- Chromium 1365×768、390×844、844×390 真实试玩检验首波 12 名、总量 36、五色选择、魔法能产生新特效、装备行囊没有水平溢出。
- 截图必须来自 **真实运行的浏览器 Canvas**，不能把参考图、概念图或静态地图当成实机效果。截图验证失败则不合并。
- 不能在未验证的情况下宣称平均 3–5 分钟：关卡时长仍取决于角色装备、难度和操作能力，只有真实计时回归后再按数据调优。
- 当前版本的皮肤与技能是**测试版迭代**；正式版写实暗黑路线独立保留。

## 已知技术缺口

怪物用旧版像素图集，并未统一匹配新的法师皮肤细节；动态光效是 Canvas 程序效果而非精致逐帧美术；当前世界生成器仍以随机石墙和柱廊为主，无法达到用户发来的宏大地牢建筑概念图中的多层房间拓扑。必须持续推进已有 F1 迷宫分支，进行实际多房间碰撞与动线验证后再声明改进。
