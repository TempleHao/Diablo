# 余烬纪事 2D · 装备命名规则（v0.6）

名字由品质决定生成方式，看名字就能大致读出这件装备是什么。规则实现在 `dist/2d/naming.js`，读档时旧名字会自动换成新名字。

| 品质 | 结构 | 例子 | 说明 |
|---|---|---|---|
| 普通 | 品相 + 基底 | 锈蚀长剑、硬革皮靴、精工塔盾 | 品相随物品等级（每 9 级一档）和材质（金属/皮革/布/骨/木/宝石）变化 |
| 魔法 | 前缀 + 基底 · 后缀 | 炽焰长剑·疾风、坚韧毛靴·旅人 | 前缀来自第一条词缀，数值达到上限 65% 时换更强的字（微焰→炽焰）；后缀来自第二条词缀；职业技能词缀用职业称谓（猎手、骸语……） |
| 史诗 | 意象 + 器称 | 血月獠牙、寂灭之冠、亡魂之握 | 意象词 36 个随机；器称由部位决定（武器、头盔、手套、靴子……各有一组） |
| 传奇 | 手写专名 | 霜吻、焚城、苍狼、晨祷 | 100 个基底各一个，短而有画面 |
| 暗金 | 手写专名 | 寒鸦的最后一吻、灰烬君王的处刑斧 | 100 个基底各一个，带人物或传说称谓 |
| 套装 | 套装名 · 基底 | 龙焰法衣·皮盔 | 一眼看出属于哪个套装 |
| 首领专属 | 固定名 | 炉誓秘杖、血印誓约护符 | 保持不变 |

所有名字由（图鉴编号、品质、物品等级、词缀、物品 ID）确定性生成，同一件装备每次读档名字都一样。
