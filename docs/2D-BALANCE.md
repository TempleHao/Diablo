# 归墟 2D · 职业平衡（满配战力上限）

目标：七个职业满配时的战力上限相差不超过 10%（用户 2026-10-24 定）。

## 怎么算「满配上限」

`node scripts/2d-balance/max-combat-rating.mjs [每部位每品质件数] [随机种子]`

- 100 级、地狱最终图；每个职业的每个流派分别计算，取最高的流派。
- 每个部位随机生成 N 件 100 级传奇 / 暗金 / 套装（本职业能穿的），全部淬炼一次，再用游戏自己的一键换装和巅峰天赋贪心分配求最高战力。
- 结果有随机波动：N=2500 时单次约 ±4%，比较职业用两个以上种子取平均。

## 平衡手段（v1.4）

1. 规则修正（对所有职业一样）：
   - 一键换装能选非弓双手武器（v1.3.1 修正的错误）；
   - 暴击伤害词缀也能出在副手和头盔上；七种元素增伤都能出在武器、副手、手套、项链、戒指上（之前物理多一个手套位、其他元素少一个）；
   - 图鉴「暗」倾向的装备优先出暗影增伤（之前漏了映射）。
2. 职业强度系数 `dmgScale`（classes.js）：乘在攻击力 / 法术强度上，**30 级以下不生效、30→100 级线性生效**，前期手感不变，只拉齐后期上限。
