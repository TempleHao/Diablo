# F0 美术与技术基线审计（2026-10-13）

本文件记录可追溯**当前可执行素材**与尚未获得的正式素材；参考图片并不是从游戏本体生成的截图。

## 已实装的可玩原型

- 主入口：`dist/2d/index.html`，Canvas 2D 绘制，不是等距 2.5D 正式实现。
- 技术版：v0.3，包含 13 槽、词缀、7 技能、五个以不同参数配置的区域，但尚无用户要求的真迷宫与持续世界流。
- 原型实机截图：`docs/screenshots/2d-v0.3-playtest-desktop.jpg`、`docs/screenshots/2d-v0.3-playtest-mobile.jpg`、`docs/screenshots/2d-v0.3-inventory-desktop.jpg`、`docs/screenshots/2d-v0.3-inventory-mobile.jpg`。
- 2D 美术引用的现有 `0x72 DungeonTileset II v1.7`：详见 `docs/2D-ART-SOURCES.md`；CC0 许可证仅覆盖已有该贴图包，不能扩展解释为其他网上素材可任意使用。
- 单元测试：`tests/2d-core.test.mjs`、`tests/2d-systems.test.mjs`；桌面/模拟手机浏览器回归：`tests/2d-browser.test.mjs`。
- 2D 动态照明 PR #4 是单独 draft，不能仅凭灯光变化宣称已完成 A 风格。

## 用户 A 向图与现有实机的明确差异

| 维度 | 用户参考画面希望看到 | 当前 v0.3 可执行内容 | 是否达标 |
| --- | --- | --- | --- |
| 镜头与地图 | 写实斜俯视的多层石造、铁栏、拱门、岩壁，主城/野外/多房间迷宫 | 平面像素地砖/简易柱子，固定场地清怪 | **fail** |
| 主角与怪物 | 成熟比例、统一写实材质/镜头与完整动画、个性鲜明 | 16/32 像素图集放大，Boss/怪物视觉不统一 | **fail** |
| Boss/刷宝 | 多阶段、专属掉宝、可重复刷且不强制重开 | 简单胜利结算/通关后进入重开流程 | **fail** |
| 装备/技能 | 真实装备图标、换装外形、厚重 UI、可比对词缀 | 系统已有 13 槽词缀和技能，但图标/换装/版式仍不足 | **fail** |
| 手机 | 有品质的竖横屏双适配、较大触区与可读画面 | 基础手机视口与摇杆，正式版品质未验收 | **fail** |

## 美术资产准入记录

- **已允许用于现有原型**：0x72 DungeonTileset II v1.7，许可证 CC0，来源和使用位置详见上方文件。
- **视觉候选 PVGames 等外部付费/收费素材**：尚未采购/授权，**不得**擅自存入公开 GitHub 仓库。只有确认许可是否允许源素材随源码公开再分发后才可使用。
- **用户提供的五张概念目标图**：用于构图、质感、配色和最终验收参考。不是切片资源，不要以嵌入游戏背景替代可交互地图。
- **新制作素材**：需要标注生成来源、素材文件指纹、版本、对应的精灵切片数据和公开使用权；若无可核实授权或用户决策，不予发布。

## 性能及画质基线

当前已知的 Chromium 原型截图和规则测试不是商业艺术验收，也不等于真机性能测试。最终还需固定场景下实测 PC 与手机横竖屏，比较人物体量、阴影、纹理、空间可读性和 HUD 遮挡，以及浏览器交互帧时间、资源加载和内存。
