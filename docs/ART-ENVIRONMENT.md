# 灰烬档案馆：环境美术重建切片

本页记录实际进入浏览器运行的环境改动。它是原创写实暗黑方向的代表切片；没有把《暗黑破坏神 II：重制版》或《暗黑破坏神 IV》的模型、地图、纹理搬入项目，也不把当前成果标为同等级 AAA 美术完成。

## 已实现的场景

- 主厅和六间侧室仍使用原来的坐标、门洞和碰撞接口。角色、刷怪与导航依赖的 `createEnvironment(scene)` → `group / obstacles / walkable / update` 接口保持兼容。
- 铺地改为 1.27–1.79 米深、不同宽度的错缝石板。四种共享石板几何带倒角、缺角和轻微不平整；没有棋盘式的等尺寸整齐方砖。低矮的磨损石条保留主路辨识。
- 墙石使用真实风化石材 PBR 表面，单块模型采样纹理中的一块真实石面，避免把一整堵砖墙缩印在每块模型表面。墙石宽度、缝隙和压顶分段有变化，暗色砂浆保留在后方。
- 柱身有共享的细肋柱，拱顶改成连续的尖拱轮廓与平行线脚。一道拱的中段缺失，与墙边碎石共同表现局部坍塌；没有在主通路添加阻挡。
- 北端的悬浮金色太阳替换为有凹凸、刻线和损角的石质葬仪浮雕。东侧锥体人偶替换为带褶皱的罩袍、空兜帽和手臂的石像。
- 墙脚和边路加入柔边焦灰、泥污与较低粗糙度的潮迹；一部分礼仪挂布底边烧损，几何本身有折褶。暖色火把使用交叉柔边火焰卡片，微幅闪动；其余细小蜡烛依然是轻量几何。
- 传送与首领仪式圈仍为可识别的游戏地标，但减弱铺满整圆的蓝/红发光，避免装饰压过真实石材。

## 资产来源与许可

`dist/textures/environment-masonry-{color,normal,roughness,ao}.webp` 来自 **ambientCG / Lennart Demes 的 Bricks 076 A**，许可为 **CC0 1.0**，可商用与再分发。

- 原始资源页：<https://ambientcg.com/view?id=Bricks076A>
- 本次使用的固定镜像：`playcanvas/engine`，提交 `3e1e7c35f00692f3bb8aad105406b6a6d7896b7c` 下的 `examples/assets/textures/bricks076a/`。
- 逐文件 URL、大小与 SHA-256：`assets-source/environment-pbr/manifest.json`。
- 上游逐资产许可原文：`assets-source/environment-pbr/bricks076a/Bricks076A-textures.txt`。
- 本项目复制未重新压缩。法线为 OpenGL 约定，即绿色通道 +Y；没有误用 DirectX 版本。

其余 `environment-*` 地板、石材、浮雕、灰污、布料和火焰贴图为本项目原创程序烘焙，与源码同属仓库 MIT 许可。没有依赖未知许可的图片，也没有把原创烘焙称为扫描材质。

可复现命令：

```sh
python3 scripts/build-environment-textures.py
```

生成器依赖 Pillow 与 NumPy，固定随机种子。它只生成原创文件，不覆写 CC0 的四张 masonry 贴图。基本色使用 sRGB；法线、粗糙度和 AO 使用线性采样。石材实际使用基本色、切线空间法线、粗糙度；墙石额外使用 AO。灰污贴花不写深度、不投影，避免矩形阴影。

## 结构预算与验证

2026-10-12 对实际环境代码进行 Node 结构遍历时，`TextureLoader` 替换为内存空纹理，以便只测几何和路网；这不是 GPU 性能测试。

| 项目 | 实际结构统计 |
| --- | ---: |
| 全场景三角面，包括所有实例 | 179,936 |
| Mesh / InstancedMesh 对象 | 171 |
| 实例与普通网格总数 | 3,365 |
| 环境真实点光 | 4 |
| 运行时环境纹理文件 | 16 |
| 环境纹理压缩文件合计 | 2,581,320 字节 |
| 碰撞圆 | 35 |

大部分石板、墙石、柱肋、书脊、压顶和挂布通过 `InstancedMesh` 合批，材料与几何共享。细书带、铁条及薄石条不使用完整石块的 60 个三角面；柱肋也采用较轻的几何。最初完整重建结构有 233,712 面，去掉这些无视觉收益的细件面数后降到上述结果。

已执行 `node --check dist/environment.js`，环境创建没有异常，全部碰撞坐标为有限数。主厅出生点、北端主路和房门点实际检查可行走。`walkable` 函数的路径限制没有改动，保留原有玩家半径的边界余量；摆件依旧由原来的 35 个圆形碰撞决定。

浏览器资源加载、代表视角截图、整局交互和实际可见绘制调用数由本轮统一美术 QA 记录。全结构数量不等于可见单帧 draw calls；启用阴影与 AO 后也不能用最终全屏三角面 2 的计数代表世界渲染复杂度。

真实 Android / iOS 手机、GPU 内存、热降频、帧率与耗电尚未实测。当前纹理预算、合批和点光限制是实现约束，不是“手机性能达标”的结论。环境仍需要在用户认可美术方向后继续精修构图、雕刻与材质；当前切片没有宣称 AAA 目标验收。
