# v0.3.4：角色比例 / 中文排版 / 手机装备流畅度复审

## 问题根因和实机处理

**1. 战斗画面比例失调。** 旧版过渡法师本地原始矢量大约 116 游戏像素高；精英、Boss 还复用放大的 16/32px 像素帧，高约 127–154 游戏像素，整体没有独立手机缩放逻辑。修复后绘制以角色脚下为中心缩放（PC 法师 0.65、怪物 0.70，手机法师 0.54、怪物 0.57；Boss 另外保留 1.08 倍识别度），原有碰撞、世界坐标和掉落逻辑不改。当前法师向更纤细的深色兜帽、窄面罩、护肩和织物阴影方向重绘；是过渡矢量美术，**不是用户参考的 A 方向写实 2.5D 精灵成果**。

**2. 中文文字挤压/变形。** 原 CSS 混用 `serif` / `Georgia` / 9px 中文字号，并存在 `word-break:break-all` 及宽字距和较低行高。现在统一中文系统字体优先级（PingFang SC、微软雅黑、Noto CJK 等）、禁用字体合成、重置正文不合理的 letter-spacing 和 break-all，特别提高手机背包物品名称、词缀和快捷按钮字号。保留系统字体回退，既不远程热链中文字体，也不擅自上传任何商业字体包。

**3. 手机背包操作迂回。** v0.3.3 把 PC 三栏（装备 / 比较 / 背包）机械堆叠到窄手机屏幕，玩家要先滚到背包选物品，再滚回中间详情，导致对比/更换步骤很多。v0.3.4 采用三个互斥标签：背包、装备对比、已穿装备；进入默认背包，点击任一物品自动到对比页，并展示当前 / 候选各自的实物图标和真实角色属性差值；底部固定“返回背包”和“穿戴/替换”，无需跨长屏操作。两个戒指槽位可主动指定，允许将当前左戒挪到右戒，不再误判成卸下。手机纵横屏分别适配，PC 保持三栏同屏对比。

## 测试和风险

- 实际浏览器检验：三视口能打开角色行囊，手机点选自动跳到对比页，双侧装备卡、底栏动作、选择戒指位置、从左戒移到右戒、自动分解设置在背包页可用，界面无整体水平溢出。
- 原版 2D localStorage 和装备材料、技能进度继续兼容；3D 代码无变化。已修复 CI 首轮提报的矢量绘制语法及手机跨页测试路径错误。
- **待推进**：高品质写实主角 8 向行走/施法/受击动画；每种怪物独立的手绘低饱和阴影与动作；高精度斜俯视 2.5D 地砖、光照与迷宫集成。当前材质仍混有低像素图集和矢量人物，不能宣称美术方向完成。

下一轮必须继续多房间迷宫 F1 分支与真正美术资产整合，以实机图片量化视觉差距。
