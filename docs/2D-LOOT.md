# 2D 掉落与装备体系（v0.7.2）

目标是向《暗黑破坏神 2》看齐：**大部分击杀不掉东西，掉下来的大多是白装和蓝装，黄装是前中期的主力，橙、绿、金装是稀有事件**。普通难度要刷十几到几十趟才见一件，到地狱、堆了寻宝之后明显变快。

v0.7.0 的问题是首领首杀必掉专属传奇，加上首领的品质加成太高，前期几乎每趟都有橙装，这一版改掉了。

代码位置：
- `dist/2d/systems.js`：`DROP_RULES`、`rollQuality`、`makeLoot`、`rollDrops`、赌博、起始装备。
- `dist/2d/boss-loot.js`：首领奖励与厄运保护。

本文的数字由 `node scripts/2d-balance/loot-report.mjs` 模拟得出。

## 1. 每只怪的掉落

| 来源 | 掉装备的次数和概率 | 品质加成 |
|---|---|---|
| 普通怪 | 1 次，15% | ×1 |
| 精英 | 2 次，50% / 20% | ×1.6 |
| 首领 | 3 次，100% / 100% / 50% | ×2.5 |

其余时候只掉金币或什么都不掉。

## 2. 品质判定

从高到低依次判定，与 D2 相同：

| 品质 | 每件基础几率 | 寻宝递减常数 K |
|---|---|---|
| 暗金（金） | 0.09% | 250 |
| 套装（绿） | 0.14% | 500 |
| 传奇（橙） | 0.36% | 400 |
| 史诗（黄） | 3.2% | 600 |
| 魔法（蓝） | 24% | 不递减 |
| 普通（白） | 其余 | — |

- **难度：** 传奇、套装、暗金在普通 / 噩梦 / 地狱分别 ×1 / ×1.7 / ×2.8；史诗和魔法分别 ×1 / ×1.15 / ×1.3。
- **物品等级：** 几率 ×(1 + 物品等级 ÷ 250)，100 级时 ×1.4。
- **寻宝几率（MF）：** 有效值 = MF × K ÷ (MF + K)，常数与 D2 相同。MF 300% 时，暗金实际只吃到 136%，传奇吃到 171%。
- **物品等级门槛：** 与 D2 相同，没有物品等级够得上的传奇或暗金时，这件降为史诗。暗金最低品级是 11，所以 10 级以前不会出暗金。

## 3. 首领

- **首杀：** 第一件至少是史诗，以后每次至少是魔法。
- **专属传奇：** 不再首杀必掉，每次击杀在普通 / 噩梦 / 地狱分别有 8% / 11% / 15% 几率。
- **厄运保护（按趟计）：** 连续 20 趟没见到传奇以上，这一趟的首领必掉一件传奇；连续 80 趟没见到暗金，必掉一件暗金。
  - 整趟里任何地方掉到都会清零，赌博赌到也会清零。
  - 暗金的保护只在已经可能出暗金的等级才开始计数。
  - 当前进度显示在状态面板（C 键）的「厄运保护」一行。

## 4. 赌博（金币消耗）

在行囊里选一个部位，花金币买一件随机装备，物品等级是角色等级 −5 到 +4。

- **价格：** (150 + 等级 × 28) 金币，戒指和项链价格翻倍。10 级约 430，40 级约 1270，85 级约 2530。
- **品质：** 暗金 0.3%，套装 0.5%，传奇 1.5%，史诗 12%，其余为魔法。
- **作用：** 金币原本只用于淬炼，基本没有消耗的地方。赌博让它有了用处，也让刷不到装备的时候还有一条稳定的路。每趟的金币大约够赌一次，平均四十来趟能赌出一件橙装以上。

## 5. 新角色起始装备

新角色自带一把本职业的普通武器和一件胸甲，开局不再空手。

## 7. 节奏

- **普通难度（1–40 级）：** 一路靠蓝装和黄装换装，黄装大约两趟一件。整个普通难度（约 30 趟）能见到 3–5 件橙装或首领专属，暗金和套装要看运气。
- **噩梦：** 橙装大约七八趟一件，开始能凑套装。
- **地狱：** 堆寻宝是主要目标，堆满后两趟一件橙装，七到十趟一件暗金。
- **刷不到的时候：** 有三样东西兜底。
  1. 白、蓝、黄装的数值随物品等级一直往上走，到了新等级段总有可换的。
  2. 厄运保护有明确的上限，并显示在状态面板。
  3. 攒金币赌博，是一条稳定的出橙路线。

## 8. 一键换装与战力（v0.7.3）

「战力」= 输出 × 生存的几何平均，用的是游戏里真实的伤害、减伤公式（含套装件数、传奇特效、擅长武器、当前流派的元素偏好、按当前怪物等级算的护甲减伤）。一键换装会逐个部位试穿背包里每一件、武器和副手按组合试，只要战力上升就换，直到不再提升；捡到能提升 2% 以上战力的装备时，屏幕上会出现「有更好的装备」按钮，点一下直接换上。

## 9. 调参入口

所有数字都在 `DROP_RULES` 一处：
- 觉得太肝：调高 `base` 里传奇 / 套装 / 暗金的几率，或者缩短 `pity` 的趟数。
- 觉得太容易：反过来调。

改完运行 `node scripts/2d-balance/loot-report.mjs` 看新的期望值。
