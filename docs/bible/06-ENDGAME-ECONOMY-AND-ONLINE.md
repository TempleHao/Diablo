## 2. 从五幕战役到个人长期目标

灰烬营地的“持灯者手记”最多显示三项自选目标：补构筑缺口、推进灯路、完成收藏故事。每项显示地点、单次时长、低难度替代路线和失败损失；可随时隐藏，不自动添加每日清单或离线过期催促。

| 阶段 | 玩家正在学的事 | 能清楚观察的完成信号 | 后续目标 |
|---|---|---|---|
| 第一幕至第二幕，建议1–20级 | 主攻、走位、元素标签，认识装备差异 | 用基础攻击也能完成必经战斗；有一个可解释的技能组合 | 选择首条路线，修复营地档案台 |
| 第三幕至第四幕，建议20–40级 | 一主变体、资源循环、防御与控制代价 | 连续三场普通战斗不会因法力枯竭停摆；装备升级理由清楚 | 获得路线常见配方，尝试混合构筑 |
| 第五幕及剧情收束，建议40–50级 | 将构筑带进完整Boss战，面对伊瑟的选择 | 完成剧情即可开启基础契约，不要求先达到60级 | 看见三条不同的终局路线 |
| 契约入门至60级 | 补抗性、优化十装备位、选择真实风险 | 两类普通契约可稳定完成，至少一种专项机制可独立处理 | 定向打造关键稀有装备、解锁邀请 |
| 60级以后 | 改变打法、挑战专项、完成个人收藏 | 目标从“更多等级”转为某件装备、某个记录或故事 | 任何一项完成后允许满意地停玩 |

建议等级不是硬门槛。低难度及所有剧情结局同样开放终局，同档奖励预算一致，只改变营地故事。角色20级及以前享有战斗章的免费重置，剧情可降低难度。第二角色可凭本地通关标记选择保留必要教学的快速叙事，不强迫重跑五幕；本机标记不能作为在线可信通关证据。

构筑成型要求一个主攻、至多两个可选主动、固定位移与药水适配五键栏，基础攻击维持输出，并有稳定防御和处理精英的办法。火焰检验区域规划，冰霜检验控制窗口，奥术检验资源节奏；数值由战斗及装备章决定，核心不依赖极稀有独特。研究点共65点：59次升级与六个支线标记；终局、重做支线及赛季迁移不得重复发放这些点。

长期目标分四层。第一层是“舒适”：以低风险6–12分钟契约换稳定材料。第二层是“专长”：选择追猎、秘藏、Boss或收藏，得到适合该目标的奖励偏好。第三层是“巅峰”：学会多阶段机制，完成灯路最终邀请和远征末段；没有只有巅峰才能获得的基础构筑部件。第四层是“表达”：外观、营地、战斗记录、极端词条自挑战。60级后不增设无上限战力点，也不把经验改成无限永久伤害；满级经验只记在手记统计中，不制造必须继续刷的另一种货币。

## 3. 秘境契约的完整一次循环

### 3.1 选单、入口与难度档

塞恩保管“灯路档案”，玩家从营地或安全城镇打开契约板。顺序是选地区与节点、选难度档、选0–3条挑战、选奖励偏好、查看损失说明、进入。基础契约随时可生成，不消耗入口物，没有体力或等待倒计时。每地区同时提供一个无词条基准契约和若干可选版本；随机列表不合适时可直接配置合法挑战，避免靠不断刷新菜单碰运气。

四档暂名巡灯、固灯、裂界、深昼，分别建议45、50、55、60级；实际怪物数值由战斗与遭遇章节校准。剧情结束时至少开放巡灯；第一次完成同档两种地图目标后出现下一档试炼，试炼可反复免费挑战，也可暂时忽略。难度档决定装备基础等级范围、配方部件可见范围和材料基准；挑战词条决定额外风险奖金。角色等级不自动抬升已经选择的地图难度，低档练习仍然可用。

奖励偏好分武器与法器、防具、饰品、打造材料四主组，之下可选火焰、冰霜、奥术、生存、法器等路线或功能标签，与装备章来源一致。双手法杖按武器与被占副手的两槽总值比较。偏好影响一个定向槽，不删正常掉落，不保证整套词条；界面列相关配方与独特来源，注明提高候选权重不等于保证掉落。

进场卡列目标、房间数、时长、风险点、奖励基准、入口消耗和死亡政策；邀请与远征另列物品损失。契约明示“等级与已拾常规装备保留，风险奖金成功撤离才结算，死亡使未结算奖金失效”。战斗不卖恢复、复活或数值补强。

### 3.2 房间、事件、选择与结算

每局由入口、2–4个战斗房、一个短事件或分支、目标房及安全出口组成，目标时长6–12分钟，房间采用经验证的模板图。每局只保证一种主事件；短分支最多两个，不把三个耗时系统同时塞入一张手机地图。地图生成先校验可达、安全通路、避让空间和镜头，再决定敌群、挑战和事件。模板不支持的词条不能生成，玩家手选同样受这一检查约束。

普通装备、金币及明确标为常规的材料在拾取时进入角色持久库存，唯一实例编号随保存事务提交；背包满时可在安全房转入营地待领箱，待领箱不扩大现场战斗优势。地面尚未拾取的物品只属于当前运行实例。风险奖金显示在契约侧栏的“待结算”区，不能装备、分解、花费或转移；主目标完成并通过出口后一次性兑现。专项挑战的未完成奖励不算已取得装备。

退出入口前可以取消；进入首个战斗房后契约固定。安全房可调整技能配置与装备，不能改变本局挑战或把已承担风险换成另一套奖励。暂时退出与正式撤离是两个按钮：“暂停并保存”保留当前实例；“结束本次行动”提交已经取得的常规掉落、放弃待结算奖励并清除实例。主目标成功后出口始终可用，额外支线不会强迫继续。契约结果显示成功、成功但风险失效、主动撤离、失败四种，避免把所有未满评分的行动都称为失败。

首次死亡保留等级和已取得装备，未结算风险奖金归零并锁定本局风险结算资格。玩家可从检查点继续普通目标，拿到一次基础结算和图鉴，或撤离；不会因死亡次数删装备。状态区分`risk_failed`（风险失效而实例继续）、`practice_only`（邀请死亡后的无奖练习）与`run_ended`（最终完成、正式撤离或放弃、无法恢复）。无奖练习保留既有拾取、不再生成或结算新奖励；死亡不自动终止普通实例，最高评分只影响记录与装饰。

## 4. 灯路秘境网络：可看见的探索方向

“灯路”是持灯者寻找断昼后仍能回应余烬炉的地点。每个节点是一份可重复进入的地图档案，边表示恢复的信号路线，节点完成记录、秘境档位和故事碎片共同构成探索图。它可以借鉴图谱式目标的可见性，但画面采用五幕各自的炉芯与记忆线，不复制现成产品的星图、技能树布局和Boss体系。

D3内容预算为15个主节点，每地区三种：通行目标、事件目标、守卫目标。灰烬边境对应废炉通道、焦木集散场、旧守门庭；盐雾海岸对应沉潮栈道、封盐仓、断帆灯塔；镜霜高地对应双镜谷、眠钟台、裂镜书室；星坠王都对应悬桥街、星砂剧场、无冠议厅；无昼深渊对应回声井、失名庭、空潮堤。名称仅是终局地点提案，需与世界章审校，不能承担另一条五幕主线。三种节点复用地区房间，但在目标、路线选择和Boss行为上有差异。

剧情完成后五个地区的第一节点都可访问。完成一节点开放本地区下一节点；完成任意两个地区的第二节点开放一条跨地区捷径。没有随机掉落才能打开的必经边，也不要求15张都刷齐才能做任何Boss。每个地区最后节点给一段档案及该地区邀请的固定线索；最末挑战需要三种地区线索，允许五选三，照顾喜欢不同场景的玩家。

每节点记录“踏查、稳定、专精”三级。踏查要求完成主目标；稳定要求在固灯或以上完成且解决该节点事件；专精要求裂界或以上携带至少3风险点无死亡完成。三级分别奖励故事记录、固定配方部件、外观或称号，不各加一份永久伤害。重复刷已专精节点仍有基础掉落，不再反复领取首次奖励。进度是位标记，无法靠删档、重复交任务转成金币。

网络专注功能有六项，营地免费切换、同时最多启用两项：优先出现追猎线索、优先秘藏机关、优先营地记忆、降低非目标装备占比、优先未完成节点提示、优先较短模板。前三项只改变可选事件权重，不叠加掉落总价值；装备筛选以减少非目标概率换取定向概率，短模板按目标时长归一化结算，不能成为最高每分钟收益漏洞。切换前显示机会成本，不是再造无限成长树。

重复喜欢的图是合法选择。若密集敌群使每分钟材料显著领先，修正基准、路径和事件成本，不加账号每日上限。首通用平价配方、收藏和有限材料鼓励探索，重复路线仍可获得同等战力；实际长期时数取决于目标密度与试玩，不承诺几百小时。

## 5. 挑战词条与真实风险奖励

以下为22个可进入数据表的首轮挑战，括号为风险点。数值是校准起点；攻击预警、屏外攻击限制、手机敌群与特效预算始终继承遭遇章。风险改变玩家决策，不关闭基础攻击、不强制换元素、不以反伤把某一路线变成必死。每局最多3条、总风险点最多6；超过6仅可在无经济收益的自挑战记录中测试。

| ID／词条 | 真正改变的规则及应对 | 可给的奖金依据／兼容边界 |
|---|---|---|
| C01 焦痕滞留（1） | 指定精英重击后留下持续4秒的小块火痕，玩家需移开 | 增加地形管理；不与大面积移动封锁同用 |
| C02 潮线推移（1） | 地面横向潮线预警后推动一步，推移不越过安全边界 | 增加站位调整；禁配强制吸附和即死边缘 |
| C03 镜影复述（2） | 指定精英攻击后产生一次明显延迟的弱化镜影，伤害不叠同帧 | 增加第二次躲避；禁配攻击加速类 |
| C04 星落碎片（2） | 地图事件后两轮标记落石，总安全面积至少保留一半 | 增加路线判断；禁配视野压缩和狭窄模板 |
| C05 空潮巡哨（2） | 新增一名沿固定线路巡逻的精英，正面遭遇或绕路任选 | 增加精英或绕行成本；敌群预算超限则不生成 |
| C06 护印侍从（1） | 一个可破坏侍从为邻近敌群提供有限护盾，不提供无敌 | 增加优先目标选择；禁配永久回血守卫 |
| C07 群体警觉（1） | 进入目标房时第二小组从可见入口增援，延迟进场 | 增加持续作战；不能同时出现第二精英 |
| C08 蓄势重击（1） | 重击伤害提高，但预警延长，安全区不缩小 | 增加躲避价值；只影响有完整提示的招式 |
| C09 快步斥候（1） | 少量杂兵移动更快，攻击速度与预警保持不变 | 增加近战压力；禁配吸附和连续硬控 |
| C10 裂壳复燃（2） | 每房首个精英死亡后留下可见复燃核心，数秒后再出一波弱敌 | 增加收尾选择；禁配持续追逐机关 |
| C11 药性迟缓（1） | 药水即时部分略减，余量转为短持续恢复，总恢复不变 | 增加施用时机；禁配持续伤害加深类 |
| C12 魔力余震（2） | 连续主动施法触发提示后，短时间提高后续主动耗法力 | 增加资源节奏；基础攻击免费，禁配法力抽取 |
| C13 疲惫灯芯（1） | 出安全房后首场战斗前30秒自然回蓝降低20%，基础攻击免费、药水不变 | 增加资源规划；禁配魔力余震，不靠延长等待计风险 |
| C14 护幕波动（2） | 指定怪攻击命中后短时间压低新生护盾效率，已有护盾保留 | 增加规避命中；不能把护盾构筑完全禁用 |
| C15 冷凝反应（1） | 一种敌人控制抵抗略升，达到阈值仍给可见减速窗口 | 增加控制搭配；禁配控制免疫模板 |
| C16 元素偏转（1） | 少量有醒目标识的精英拥有单元素中等抗性，不超过上限 | 增加目标识别；禁止全地图三元素高抗 |
| C17 紧闭侧门（1） | 一条捷径关闭，但完整主路与退路保留 | 增加跑图成本；只能用于有冗余路线的模板 |
| C18 运灯护送（2） | 目标改为推动可停靠灯车，两停靠点都能安全整理装备 | 增加守护目标；只限护送节点，禁配持续推移 |
| C19 双印解锁（1） | 出口需先激活两个分离印记，顺序自由，地图标出路线 | 增加路线选择；不能与侧门同时封锁必经点 |
| C20 贪藏警报（2） | 玩家主动开启第二秘藏箱会触发一场标明配置的守卫战 | 增加自选战斗；没开箱不算有效风险点 |
| C21 再临守卫（3） | Boss最后阶段增加一轮原创组合招式，先提供无奖练习 | 增加机制学习；禁配镜影和攻击加速 |
| C22 不息追光（3） | 可见追逐机关在战斗房间歇启动，进安全房自动休眠 | 增加持续走位；禁配地板滞留、吸附、护送 |

风险点只有实际启用才进入结算。比如C20进入时显示“完成第二秘藏箱守卫后激活2点”；未选分支则奖金不含这2点。C17必须实际关闭捷径且主路更长，模板里没有捷径不能白送风险。C16必须保证候选精英出现，不能掷空后照常计奖。条件是否达成写在状态栏，结束页显示每条贡献，避免纸面词条与真实战斗脱节。

风险奖励包括精华或秘纹碎片加成，以及达到阈值的同档装备候选，全部托管，死亡失效、成功兑现才生成可用物品，不扩大最高词条范围。设材料基准B、有效风险点P，额外材料初值为`floor(B × min(0.60, 0.08 × P))`，只算一次并与基础奖并列；由偏好与活动选择材料，不对两种同时加成。P达到3增加一次同档装备候选抽取，达到6再给一次，不保证独特、不突破品质和ilvl上限。此式需与装备章分解收益校验，避免刷装分解胜过材料目标。

禁用组合不是只列两词条：生成器还检查模板、敌群、Boss阶段与角色基础可解性。硬控加伤害地板、吸附加致死边缘、视野遮蔽加远射、双机关封死安全区一律禁；C03/C21加速复述不能撞上同一Boss；C01+C04+C22任意两项都需空间测试，默认不允许；C11+C12+C14不能三项同开以同时压垮药水、法力和护盾；C18+C02、C18+C22、C17+C19在无冗余通路图禁用。若随机组合验证失败，回退到已验证的低风险版本，显示调整原因，不暗改玩家已确认的奖励卡。

任何词条在最低支持机上达不到预警或通路底线，先下架该组合。测试以三路线的常见稀有装加基础符文尝试，不能拿完美独特装作为“可解”证据。高风险每分钟期望收益应略高于熟练玩家的低风险收益，死亡后的实际收益可低于低风险；若所有玩家都无脑勾满，则风险不真实，若多数玩家避开同一词条，则检查触屏公平性和奖励成本。

## 6. 事件与专项终局目标

下列十二项各给出触发、操作、失败和收益，作为内容资产预算。基础目标一次6–12分钟、Boss目标3–8分钟均是试玩目标。前十项适合D3，后两项先做可用的小规模版本；扩展数量不能成为单人发布前置。事件不使用真实世界时间，也不需要当天上线。每项都有低档入口和完整线索，不以攻略网站代替游戏教学。

1. **余烬炉回火。** 通行节点出现两座失稳的小炉，玩家先看见各自对应的敌群标签，任选一座校正，再打断三次外露引流。选择保护炉体会少一波怪、少一份风险奖；选择过载会开启额外守卫并标明奖金。炉体毁坏仅失去本次事件奖金，主出口不锁。首通给诺娅营地故事，重复给固定精华与一件本地防具候选。
2. **沉潮记忆打捞。** 盐雾节点有三条可见潜流，按提示开闸后拾取两个漂流记录，最后一条可选精英路线。玩家可用移动而非强制位移穿越安全间隔；潮水不会消耗装备耐久。漏失记录可重试下一局，不损已有记录。两件任务记录兑换一次原始配方部件，之后为金币和饰品偏好；记录不是可无限交易货币。
3. **眠钟校律。** 镜霜高地给三个相同颜色以外也有形状标记的钟，听觉与文字提示均能解谜；玩家按现场显示节奏激活，战斗阶段保护已校钟。无计时解谜版保证色盲和静音可用，挑战版只是额外怪波。错序重置本轮钟序，保留常规掉落。完成获得当地记忆页与秘纹碎片，重复收益按实际战斗时长校准。
4. **无冠审档。** 星坠王都的档案室可从三份案卷选一，分别偏向群怪、精英、短Boss；提交前显示奖励与机制。案卷内容联系伊瑟如何征收余烬，玩家解决证据冲突而不是重复看无关对白。战斗失败仍能读已发现证词，经济奖只给成功目标。三案首次各完成解锁装饰，重复给选择过的装备组候选。
5. **空潮锚定。** 无昼深渊的三个锚点轮流暴露，玩家先处理护锚敌群，再在安静窗口交互，不能站着长按挨打。每完成一点立刻保存任务进度，本局中途撤离可带走已拾普通战利品；全部锚定才有风险结算。首通是最终邀请的一条线索，之后固定材料。锚点失败不删除已经完成的第五幕结局。
6. **署名追猎。** 在任一节点取得明确猎物线索后，从契约板任选当前线索的追猎地图。首房判断两种踪迹，正确选择缩短路程，错误选择遇到普通敌群后仍通向猎物。精英拥有一个可观察的逃跑行为，逃跑一次转入固定第二房，不无限追逐。首杀记入怪物图鉴；重复偏向护符、戒指或该猎物配方部件，不给必须每日刷的悬赏币。
7. **三印秘藏。** 短分支由可见机关、封印卫兵、宝库三段组成；任选两个封印可开普通库，三个全开加守卫战可开风险库。打开前明确普通物品即时取得，额外箱为待结算奖励，死亡会失效。每局箱子及其物品编号唯一，暂停恢复不能再开。低档提供常见宝石与符文物品，高档给同等级打造候选，无独占必需符文。
8. **失名隐室。** 五地区各设置一组线索图形，完成两条对应支线后在契约地图上能看见可调查墙面；成功调查后该隐室加入档案，后续可直接选择。隐室是短故事与一次收藏奖，不是长期无法预测的刷装捷径。若错过可以从塞恩查看文字线索，无需反复撞墙。D3先做每地区一室，追加隐室属于内容扩展。
9. **守门人邀请。** 各地区第三节点的线索组合成该地区邀请函，制作配方显示来源且基础线索可重复取得；三次指定节点完成提供一张邀请的确定性兜底。进入首个Boss战斗才消耗邀请。Boss新增一项地区机制，完成后固定给配方部件并抽取其候选独特装备；连续未出目标的保底计数规则由物品章统一。死亡可继续无额外奖励的机制练习，整次奖励资格失效，仍可退场。
10. **伊瑟的余火试炼。** 任意三地区稳定档案和三类线索组成最终邀请，只是记忆中的终局试炼，不推翻剧情抉择。战斗三个阶段分别检验地形、优先目标与资源窗口，没有考验具体元素的硬免疫。首次完成获得剧情后记和炉芯装饰，重复掉落偏向十装备位的高档候选；更高风险可给外观记录，不给独占基础战力。失败保留档案，不要求重新完成五幕。
11. **深渊远征。** 从已知线路选一，每线六段、每两段一座休息炉，单段4–6分钟、完整约25–40分钟。单段基础结算成功即提交；休息炉兑现此前两段风险奖，保存后可回营地，再入从下一段继续、不重领奖。每段选精英、机关或材料分岔，标出下个休息炉距离。死亡损失上个休息炉之后整批未结算风险奖，本批风险资格失效；可继续普通目标，到下个休息炉才恢复新批风险资格，整程无死亡评分仍失效。已提交奖和装备保留，也可直接结束，不删角色。
12. **复灯营地委托。** 诺娅、塞恩、瓦尔分别给维修、编录、护路任务，玩家从三份长期委托中任选一份，完成两次对应事件即可交付。委托没有日刷新、缺席惩罚和连续签到倍率；更换保留已发现故事，但不同时领取重复经济奖。首版各三条短故事，奖励设施外观、公共配方和金币，不能让未做委托者缺少治疗、重置或终局入口。

远征D3先做两条六段线，第三条是预算余量，不承诺无限深度。存取、温升和恢复先验收再扩长度。邀请与远征增加机制而非只倍增生命；追猎、秘藏、隐室各有目标，不能都被同一种随机部件卡住。

**训练木桩属于完整单人基础设施。** 营地提供单目标、三目标、移动目标、护盾与抗性预设，预设必须显示确切防御条件；可锁定自身当前装备，记录30秒和60秒伤害、主动施法次数、法力最低值、持续伤害占比、命中与触发来源、受伤模拟下的恢复。读数仅用于同设置比较，不把木桩输出当真实Boss排名。它不给金币、材料、经验和成就进度，不能挂机产出；退出清除测试临时效果。耗时可由玩家停止，战斗回放数据在本地保留最近几次即可。

**雇佣随从是可选单人扩展，不是D3通关或构筑前置。** 首版先完成三路线独立可解，再评估一名“护路见习员”。随从不占玩家十装备位，使用固定等级模板与两种免费营地职责：拉开杂兵或提示机关；不新增第三套装备刷取体系，不自动拾取、替玩家触发秘藏或获得独立掉落。Boss战只提供低权重辅助，不能代做必须由玩家识别的核心机制。倒地本局停止协助，安全房免费恢复，不花金币买复活。若随从令镜头、寻路、威胁识别变差，则保留营地故事角色，战斗随从推迟。

## 7. 收藏、声望与营地为何值得回来

收藏图鉴分怪物、地图、余烬记忆、配方和外观。怪物首杀解锁描述，已观察机制显示提示；地图可直达已知节点。故事分别记录找到与阅读，不读完也能领战斗奖。配方显示学习状态、来源与已有部件，不让任务物失去用途说明。

成就采用可完成的有限目标：三路线各完成一次基础契约、五地区首次踏查、解锁五隐室、在指定Boss机制下无伤完成一次、用非独特核心构筑通关试炼等。奖励称号、旗帜、营地装饰和外观；不增加伤害、药水量、可交易稀有材料。每条成就注明是否需要无死亡、是否允许降低难度、是否允许随从，符合条件时即时锁定完成标记。已有成就不因平衡改动取消，只记录完成时版本；版本显著改变的挑战建立新记录。

声望不是新增消费货币。三名营地伙伴各有四级关系进度，通过不同一次性支线和可重复委托推进，每次来源和剩余需求可见。一级开放故事与基础设施，二级给常见配方的替代获取路径，三级给装饰套件，四级收束伙伴故事。相同可重复委托推进幅度有限并有总需求上限，不设置每日上限；玩家可连续完成，也可以停一月后继续。任何设施功能不要求全声望满级。

营地修灯台、档案台、练习场、仓库分别提供打造、索引、木桩、整理与导出，随战役早期固定开放。升级以支线和金币为条件，改善方案保存、整理与外观；基础容量和待领处理先保证刷装便利，不预设出售容量优势的商业模式。

装饰摆放限制在营地网格和性能预算内，不能挡住交互、出口或扩大碰撞。炉芯颜色、伙伴留言、地区旗帜和纪念牌表达玩家做过什么。来源页允许预览未获得装饰并追踪长期目标，限时赛季装饰未来可在永久模式经替代挑战获得，避免用错过就永久绝版迫使上线。支线可以给经验、金币、基础配方、部件和故事，但第一份路线必需配方至少有固定战役来源，不要求声望或隐藏区。

## 8. 掉落随机与打造确定性各自负责什么

随机负责惊喜和差异：同档装备的基础类型、合法随机词条、品质、独特的浮动值，以及非必需稀有外观。确定性负责可制定计划：必需符文与路线基础配方、普通材料收入、任务奖励、首次邀请线索、指定打造所选词条的操作结果、长期目标保底的记录。相同材料不应一会儿被写成固定、一会儿又按随机概率损失；具体打造费用与稀有3–6词条、最多3前缀3后缀等规则引用物品章，不在这里另造品质。

巡灯至深昼提高基础等级与合格词条范围，公开映射装备章的ilvl，最高暂定75；角色60级不等于所有掉落75级。普通稀有装先能完成下一档，独特再改变打法。普通与魔法仍可作底材，免费过滤及常见材料自动拾取控制手机可读密度。额外风险扩大同档机会与材料效率，不锁路线核心。

打造缺口以“目标栏”解释。例：冰霜玩家已具备控制循环但衣袍缺防御词条，先选择防具偏好、完成可见配方来源，再以固定材料操作补上一项可选防御；之后继续刷取更合适的稀有底材。若火焰独特迟迟不出，常见稀有装和符文仍能完成火焰路线；独特来源页给出固定专项来源及保底进度，最高浮动值不必保证。奥术玩家比较双手法杖与魔杖法器时必须合算两槽，不可在目标栏只显示单件面板。

三资源有不同消耗理由。金币用于既定打造费用、店铺底材和营地表达；精华用于装备相关加工与常用符文操作；秘纹碎片用于符文或配方的既定高级操作。实际操作清单与价格由物品章统一，终局只提供来源映射。没有离线金币利息，没有上班后欠下的维护费，没有一天不修炉就降低全角色属性的衰退。消耗不通过装备随机损坏制造，而通过玩家主动追求新构筑与升级来产生。

玩家可以持续刷喜欢的低档，但存在有限价值上限：物品等级不能突破该档，首次奖励不能再次领，高阶配方在可读来源处取得。低档材料仍可积累投入高阶打造，不因达到60级全部贬为废物。每分钟基础收益按地图实际完成时长对齐，短Boss不应同时获得整张地图的金币、材料和装备次数。若出现“进场捡箱立即退出”最佳策略，调整箱子收益与目标资格，保留退出自由，不加体力解决。

## 9. 失败、中断、存档与重复刷取

| 情况 | 玩家保留 | 本次损失 | 恢复或重试方式 |
|---|---|---|---|
| 普通契约死亡 | 等级、已拾装备、已提交材料、已解锁剧情 | 全部未结算风险奖，本局风险资格 | 当前检查点练习并拿一次基础结算，或退出免费重开 |
| 主动放弃普通契约 | 已取得常规掉落、已提交图鉴 | 未完成基础结算、未结算风险奖 | 任意时刻新开，无冷却与账号惩罚 |
| 邀请战失败 | 已取得常规掉落、邀请配方、完成的地图档案 | 已激活邀请及该局未结算专项奖 | 无奖练习或退场，确定性线索可再次制作邀请 |
| 远征段落死亡 | 已提交基础奖、休息炉前已兑现风险奖、全部已取得装备 | 上个休息炉后整批风险奖、本批风险资格、整程无死亡评分 | 继续普通目标；下个休息炉恢复新批风险，或结束 |
| 标签页切后台 | 已提交的一切和活动实例 | 正常不产生经济损失 | 单人立即暂停，回前台确认后继续 |
| 浏览器崩溃或设备重启 | 最近已提交状态；完整提交的物品 | 极端情况下尚未提交的地面掉落 | 恢复同一实例及确定种子，不能重抽已生成奖励 |

默认没有降级、扣经验、装备掉落、全金币罚款、借贷复活或五幕重置。死亡动画之后屏幕直接列出损失；玩家第一次入契约前用一张教学卡解释“常规拾取立即保留，风险奖成功兑现”。邀请消耗以首次进入可战斗状态为提交点，加载失败或未开始战斗取消不扣；开始后不能通过刷新网页退还入口物。

本机存档应以IndexedDB事务保存角色、运行实例与结算日志，采用递增修订号与唯一领取标记。拾取、开箱、激活邀请、完成房间、兑现风险奖各是原子提交：物品写入与箱子已开同时成功，入口消耗与实例激活同时成功，奖励入库与结算已领同时成功。退出恢复读取最高完整修订，重放未完成提交时依幂等键判断，不再发放已有物品。两个标签页用本地写锁或单一写入者协商；冲突标签页只读，提示回到活动页，不各自推进经济。

活动地图保存种子、随机数状态、房间目标、已拾实例ID、敌群生成结果、箱子与风险状态；安全房保存后可跨会话恢复。战斗中崩溃恢复至最近战斗快照或房间入口，已提交的拾取和消耗保持单调，复建敌群不能再掉已登记奖励。不得提供实时任意回档复制装备的功能。为了简化实现，D2可仅允许安全房退出保存；D3须把意外关闭的损失控制在一房内并明确提示，但不能把崩溃当故意死亡直接扣未结算奖。

导出文件包含版本、修订和校验信息，导入用于换机、备份和灾难恢复。单机玩家能够修改本机资料，客户端校验和只能发现意外损坏，不能证明公正；本地导入与手动编辑存档永远不可直接进入未来可信交易、排行榜或赛季服务器。在线同步不接受“最后时间戳最大就全部覆盖”规则，服务器另有权威流水与冲突政策。D3导入前显示当前档案与待恢复档案概况并保留一份本机备份，选择具体档案后整份替换，不能把两份库存合并套利。

重复刷取合法，挂机生产无收益。木桩、城镇战斗模拟、已结算Boss练习不产出资源；退出再入不能重复首次奖励，恢复同实例不能重新抽箱。低档保留稳定收入，不采用账号级收益递减惩罚长时玩家；若需要防止同一异常行为，则修正目标或掉落资格并公开规则。玩家停玩后回来，角色、地图与委托不倒退，补丁迁移提供构筑重置和失效装备说明。没有强制每日、周限额、连续登录、过期悬赏或体力；可选提示只推荐玩家已选的目标。

## 10. 未来在线服务：独立的D4项目

下列模式均不是GitHub Pages单人首发前置。静态站可以提供本机运行、导出文件和模拟记录，不能独立提供可信经济、权威战斗或全球排行榜。每项要另立预算、用户需求、服务可用性指标和退出政策；先做完整单人游戏不表示这些成本自然消失。没有在线权限也能完整体验五幕、三路线、契约、邀请与收藏。

### 10.1 身份、云存档与合作

云存档可独立交付，需账号恢复、会话令牌、加密传输、迁移、冲突预览、历史备份和删除数据路径。同步单机档标“本机来源”，不代表可信；可信角色在服务器创建并验证，既有本机角色继续单人。同步失败仍可本机保存，恢复后选择整份分支，不任意合并库存。

合作先评估2人私人队伍，不承诺公共大世界或跨区即时匹配。两人各自保有五键与十装备位，地图按双人威胁预算重新验证，Boss增加目标分工与可读机制而非简单生命翻倍。战利品个人分配，任务进度按实际参与记录，入口物由发起者承担并在开始前显示。掉线有短重连窗口；副本由服务器保留，伙伴可继续，掉线者奖励只依据已参与目标，不给城镇挂机者完整收益。复活次数与倒地规则必须另行试玩，默认普通合作仍保留等级和已取得装备。

后端需要权威副本状态、动作输入验证、敌群AI、碰撞或可验证命中、掉落事务、房间快照、连接转移与版本一致性。手机网络延迟决定是否做服务器全模拟或约束式验证；没有定下方案前不能宣称客户端命中可信。主要成本是每同时在线副本的CPU与内存、持续网络流量、跨区延迟、故障恢复和客服。先测2人低并发封闭房间，达到丢包与断线恢复标准再扩4人；团队未预算运维值守时保持单人。

### 10.2 交易及物品绑定

交易会改变所有掉落的价值，必须单独开放，不作为构筑成型的解法。建议只在可信永久普通池与各可信普通赛季池内部交易，池之间禁止跨流通，硬核不开放交易。任务物、邀请线索、剧情奖励、成就和装饰绑定账号；装备首次穿戴或执行改变词条、孔位、符文的打造后绑定账号，普通拾取且未改动的合格装备可交易。独特若开放交易同样遵循装备绑定，不通过换皮解除。绑定详情写入物品，交易预览显示，不用玩家口头约定。

首轮只做双方在线的金币与未绑定装备交换，材料及入口物不流通，避免把全部系统变成市场；不设匿名现金交易、付费提高掉落或付费绕过绑定。交易需双方确认同一最终报价，修改任何物品或金币均撤销确认；服务器冻结相关库存、检查所有权与绑定，再一次提交双方转移。超时、断线和重试依交易ID回到完成或取消状态，不出现物品已扣但钱未到账。手续费若采用，只以金币显示并参与经济仿真，不先用高税率替代反作弊。

后端成本包括权威库存账本、不可重复的物品ID、原子交易、审计日志、搜索与限速、异常追查、申诉和市场运营。自动市场与离线订单需要托管、价格历史与更多客服，属于下一阶段。正式开放前证明分解、打造、赠送、死亡和迁移都不会破坏绑定；出现复制漏洞时按受影响池暂停交易并调查流水，不直接全体删装备。单机存档、开发工具物品和迁移测试物品不得进入该池。

### 10.3 赛季及永久档迁移

赛季是可选的有限主题规则实验，默认永久角色不重置。建议12–16周仅是运营评估起点，必须证明新增主题足够且团队可持续；没有内容预算就不安排固定季度更新。玩家主动新建赛季角色，保留账号已有外观和已看剧情标记，战斗等级、金币、装备、地图进度从新池开始；可选择跳过已看叙事并走快速教学，但不把永久角色库存带入新经济。赛季仍只有现有法师路线，主题不靠承诺新职业撑规模。

开季前发布每件主题物品结束后的处置：保留普通基础与词条、主题能力移除并替换为明示的普通效果、或作为无数值纪念物入收藏。需要转化的装备提供合法模板与可用替代，不让玩家迁移后出现占用装备位却完全失效的核心物。主题专用任务部件清理前给出用途截止提示，但永久材料不被清空；未完成的赛季故事可转成永久回顾，赛季竞争记录冻结。赛季奖励以外观、故事、记录为主，不给永久角色必须参赛才能获得的长期战力。

结束时冻结赛季写入，生成批次及清单，用幂等批次ID把角色、等级、物品、三资源、配方、收藏及合法研究点获取标记移到同来源永久池，迁移不重发升级或支线点。05定义的按角色+来源+目标记录的独特保底计数、补缺领取进度和首次奖励来源键，也随原角色及其规则版本迁移，不重置、不合并到另一永久角色；新建赛季角色从零记录这些进度。普通进永久普通池，硬核进永久硬核档。仓库进入只取页，逐件领取记录实例ID；容量不足可保留，无仓促领取期限。装饰合并完成标记，绑定不解除，成就保留版本与模式。

迁移维护中禁止交易和打造，失败批次可从日志重试而不能由客服手动复制整份资产。赛季内已结算奖励参与迁移，活动实例强制安全结算到最后休息点，未结算风险奖励按赛前公布的终止政策放弃，不给跨池继续刷取的实例。正常模式死亡没有删等级装备；赛季结束也不是角色死亡。本机主题模式未来可做离线实验，但标记为本机来源，不能假装已进入可信赛季。成本包括新内容、独立经济池、数据迁移演练、平衡、公告本地化、回归测试及赛季期客服。

### 10.4 硬核、排行榜与反作弊

硬核必须由玩家在新建角色时主动确认，并始终显示图标。建议首轮采用“死亡后转为纪念档”：不可再战斗、不交易、不分解，保留装备展示、故事与死亡原因；永久普通角色完全不受影响。不允许死亡后把硬核装备转普通仓库，也不以硬核提供更高数值装备。硬核赛季结束时活角色进永久硬核档，死亡纪念档随同归档；两类都不转成普通经济资产。硬核云服死亡判定必须来自权威事件，断线、客户端崩溃与延迟处理先有测试和公开政策，再开放该模式。若服务器事故能被流水证明，采取按事故范围统一处理的事务恢复，不受理玩家任意时间点回档换取复制资源。

排行榜先做固定种子、固定档位、固定规则的可选挑战榜，按三路线主标签、单人与合作、普通与硬核、版本分别分组。分数由目标完成、时间、死亡和可验证的风险组成；不把财产多寡或无限经验作唯一榜单。显示前100和玩家附近排名，不以排名发放独占战力；赛季榜冻结历史，平衡改动后新版本重新记录。导入存档和本地编辑角色只能看自己的非认证成绩，不与可信榜同列。

榜单需要服务器认可的种子、开始与结束时间、规则版本、输入或摘要回放、异常成绩复核及申诉。客户端上报“伤害一亿、完成一分钟”不是验证；单机伪造校验和、隐藏JavaScript或混淆代码不能建立权威性。若无法承担重放或服务验证成本，公开个人最佳和可分享记录即可，不部署看似可信的全球竞争。

反作弊分三层：权威资源事务阻止复制与越权；战斗约束与回放识别非法速度、射程、触发频率、伤害和不可能路径；运营层处理自动化、恶意交易与漏洞传播。所有处置基于规则版本、证据日志与可申诉记录，不凭一次异常延迟直接封禁。检测优先使用服务器事件及最小化遥测，不索取无关本机文件。资源审计存聚合与关键流水，战斗回放限定保留期，成本是存储、查询、人工复核和账号安全。单机允许玩家编辑体验，但其来源标记永远不获得在线可信资格；不能为了保护未来市场妨碍正常离线运行。

## 11. 三种三十分钟会话

以下都是目标节奏，不是实测留存承诺，也不要求玩家每天完成。剩余时间不足时可选短目标或保存，系统不把30分钟变成最低开局门槛。

**刚通关的冰霜玩家。** 前3分钟看目标栏“稳定法力与衣袍防御”，免费配置基础符文、选巡灯防具偏好；接着9分钟完成无挑战的废炉通道，得到常规稀有衣袍与固定材料；用4分钟比较旧装并做一项既定打造；再9分钟做眠钟校律取得配方部件；末5分钟在木桩观察30秒资源循环并保存构筑。成果是一个可解释的防御升级和两个踏查节点，不要求独特掉落，也未用完任何每日机会。

**已成型的火焰玩家。** 先用4分钟查看守门人邀请缺一条追猎线索，选固灯署名追猎和2风险点；8分钟解决猎物后兑现奖金，制作入口物约2分钟；5分钟进行邀请战，在最后阶段死亡，保留沿路拾取物，失去邀请和待结算专项奖；再用6分钟无奖练习理解招式；末5分钟记录失败原因、查看确定性线索来源并回营地。此次没有掉等级或删已取得装备，仍学会下一次应对；系统不卖复活、不承诺失败必定收益最大。

**重视故事的奥术回归玩家。** 3分钟查看一个月前保存的远征，休息炉前奖励已领、下一段未开；8分钟完成第三段并拾取普通装备，7分钟做第四段到休息炉结算，明确保存远征；5分钟交塞恩长期委托看失名档案，4分钟摆放获得的旗帜并比较魔杖法器与双手法杖的两槽总值；3分钟导出备份后退出。没有补签、过期损失或要求立刻打完后两段，明天、下月恢复规则相同。

## 12. 数据契约、预算和验证

### 12.1 最低数据字段

| 对象 | 必需字段 | 不能省略的用途 |
|---|---|---|
| ContractDefinition | id、地区、nodeId、tier、模板集合、主目标、奖励组、时长目标、合法挑战 | 验证目标可达与奖励对应，不靠文案猜规则 |
| ChallengeDefinition | id、版本、riskPoints、触发条件、实现参数、标签、禁配标签、模板需求、奖资格 | 保证显示词条真实生效，更新后旧局仍可解释 |
| ContractRun | runId、seed、rngState、规则版本、房间状态、敌群结果、挑战、有效风险、riskBatchId、失效原因、无死亡评分资格 | 同实例恢复；远征按批恢复风险，整程评分不恢复 |
| RewardLedger | transactionId、runId、sourceId、riskBatchId、itemInstanceId、常规或风险、状态、领取修订、数量 | 待结算不可消费，逐批失效或兑现，领取幂等 |
| ProgressArchive | 账号来源、角色ID、五幕标记、节点三级位、邀请线索、配方、成就版本、伙伴关系 | 区分永久成长和单局资格，不混入新货币 |
| SaveEnvelope | schemaVersion、revision、完整提交ID、活动运行、写入者租约、校验、导入来源 | 检测损坏和多页冲突；校验不代表反作弊 |
| OnlineItem／Realm | 物品所有者、绑定类型、绑定原因、经济池、赛季ID、来源与交易记录 | 阻止跨池、解绑、纪念档转移和不可信导入 |
| SeasonMigration | batchId、源池、目标池、主题转化表、资产清单、逐项完成标记、失败状态 | 迁移可重试而不复制库存 |

奖励流水区分生成、拾取、托管、兑现、失效；物品只有一种所有权状态，失效风险候选不产生可用实例。首次奖励以来源键唯一约束，档案与结算共用真实状态；剧情、收藏、经济同事务提交，避免图鉴完成却没到账。

### 12.2 交付内容预算

| 阶段 | 最小可审查范围 | 明确延期项 |
|---|---|---|
| D1垂直切片 | 一地区两种契约目标、3条真实词条、1事件、死亡托管说明与幂等结算 | 完整网络、邀请链、在线 |
| D2系统Alpha | 三路线与十装备位、五地区数据入口、6节点、8词条、4事件、木桩、安全房恢复 | 完整五幕叙事、最终邀请、远征长线 |
| D3完整单人 | 五幕；目标15节点、22词条、12事件资产；5地区邀请与1最终试炼；两条六段远征；5隐室、9伙伴短委托 | 战斗随从可延期；第三远征、无限深度、更多职业 |
| D4在线项目 | 各项独立原型、成本与故障演练通过后逐项开放 | 合作、交易、赛季、硬核、榜单互不绑为首发门槛 |

“12事件”按本章事件资产计数，不能把同一打怪任务换名字算成十二种；邀请与远征的规模另计，场景可以复用但关键操作不同。若预算不足，先减少节点装饰变体和重复事件次数，保留三路线可成型、无每日门槛、确定性来源和可靠恢复；再减少可选远征线路和随从。任何缩减需要回写内容预算，不能留一个空入口表示系统完整。

### 12.3 指标与失效风险

体验验证目标包括：新通关玩家能在一分钟内说明下一目标和失败损失；常见装备三路线均能完成基础档与至少一专项；普通契约中位完成时间落在6–12分钟、Boss在3–8分钟；同档主要地图每分钟材料收益不出现大于约20%的无风险差距；第一项指定缺口改善能在2–4次契约加一次确定打造内看见。上述均是首轮门槛，样本须覆盖新手、熟练者和最低支持手机，不写成已经达到的结果。

奖励验证按完成、死亡、撤离三种分别统计实际净收入、入口成本、定向装备达成次数和长尾；只看完成者收益会隐藏新手被高风险榨空。记录挑战选取率、真实触发率、死亡原因、禁配回退和每分钟收益。某词条触发率低却常被选满是免费奖金风险；某路线总避开同地区可能是抗性偏置；某模板被刷到统治全部目标要查奖励与路径；独特长期未出造成停滞则检查基础构筑替代和统一保底，而非直接卖掉落。

可靠性测试必须覆盖开箱后刷新、拾取瞬间关闭、邀请消耗中断、风险兑现重复请求、两页并发、背包满、导入旧版本、远征跨会话和迁移中断。验收是已提交物品不丢、同源奖励不多领、重开不退已激活入口物、单机正常死亡不删既有装备、失效风险奖不能花费。测试日志能重建一局资产变化才有资格扩展交易；在线事务、绑定和迁移再做并发与故障注入，不以单机界面跑通代替。

内容失效的主要风险是事件变为停下来读长文、每局机关太多、随机组合只有惩罚没有选择、制造成本比刷装更不可预测、声望变相签到、所有最优收益集中在一个Boss、满级后只剩无限数值。分别用可跳过故事、主事件上限、禁配验证、明确费用、长期委托、收益归一化、有限专项目标应对。手机层面还要检查远征温升、持续后台恢复、镜头和特效遮挡；不过关就缩短段落或减少并发组件，不能要求玩家换设备弥补规则不清。

发布必须证明玩家能在游戏内选目标、查来源、理解失败、安全离开并继续。在线扩展经独立服务和运维验收后才进入承诺。
