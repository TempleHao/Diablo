# 2D v0.3.2 Demo 改版清单和验收记录

本版是用户要求的 **可玩 Demo 更新**，目标是改善现有游戏的装备交互和 Boss 战后的探索衔接，**不会代替独立的 A 方向写实暗黑 2.5D 最终重构**。不涉及原 3D 游戏文件或存档。原 2D 的 localStorage 键沿用不变。

## v0.3.2 的实际交付范围

| 优先级 | 项目 | 已实现的代码 | 验收标准 |
|---|---|---|---|

## 运行机制及注意事项

- 传送阵会出现在 Boss 倒地处，右下附近出现“传送阵已开启”的入口按钮，PC 也可按 `T`；点击“进入指定地图”会启动新的探索场景。传送不会自动删除上张地图的未拾取 Boss 传奇装备（已存入旧的本地存档）。
- 九个区域此阶段仍沿用现有 Arena 地图生成器，只实现不同基础布局参数、随机装饰及地域 Boss 组合，**尚不等于 F1 正式多房间迷宫已经合并上线**。F1 真实迷宫继续在 PR #6 开发分支，不要把两个目标混为一谈。
- 装备矢量插画由项目代码自行绘制，未使用受限第三方素材，但它也不是此前 A 方向高精度写实物品图。当前更准确的表述是“类型正确、风格统一的过渡 UI 插画”。
- 九个 Boss 目前复用基于现有图集的主要战斗角色和技能动画，尚缺九种独立 Boss 外观/动作；新区域和新 Boss 的完整美术属于后续正式制作任务。
- 手机独立布局以原有纵屏控件为基础；角色装备页采用完整可滚动的装备/词缀/背包工作区，非一次性压缩到 390 像素宽屏内。

## 自检门禁

必须通过纯规则和浏览器运行回归：

1. 9 个有效区域、可重复随机旅行且不抽到本区域、所有目的地有效。
2. 9 个 Boss 具有各自独占传奇，首杀掉落确保有效，旧数据迁移到 9 区保持既有装备。
3. 法杖/剑/匕首/盾/书/戒指/头盔轮廓匹配；五档边框区分品质；没有从互联网获取不可分发素材。
4. 真实浏览器执行一次 Boss 击杀，传送阵真实出现；打开弹窗，选下一张地图后页面实际更新对应区域；完成后仍可操作。
5. 真实 PC 1365×768 与手机 390×844 截图，确认三栏/纵向切换、背包筛选和穿戴、文字内容不水平越界。
6. 不声称通过未执行的真机 iOS/Android 性能、横屏或完整游戏通关测试。
